# Predictor + 单帧 DiT 复现流程

本文档描述当前两模型主链路。Predictor 与 DiT 独立训练；DiT 训练时在线调用
冻结 Predictor，不保存离线 prior store。数据契约以 [contract.md](../contract.md) 为准。

## 1. 路径

```powershell
$RepoDir = "D:\code\DiffusionPoser"
$AmassDir = "D:\datasets\AMASS"
$SmplModelDir = "D:\datasets\body_models"
$BodyFbxRestJson = "D:\code\SIGGRAPH2024Unity\Assets\Projects\RealtimePose\Models\DiffusionPoser\body_fbx_rest.json"
$ArtifactRoot = "D:\DiffusionPoserArtifacts\predictor"

$SourceDir = Join-Path $ArtifactRoot "source"
$TaskDir = Join-Path $ArtifactRoot "tasks"
$NormalizerDir = Join-Path $ArtifactRoot "normalizer"
$PredictorDir = Join-Path $ArtifactRoot "runs\predictor"
$DiTRunDir = Join-Path $ArtifactRoot "runs\dit"
$SplitDir = Join-Path $RepoDir "data_loaders\splits\RPM-P2"
$IKCalibration = Join-Path $ArtifactRoot "ik_calibration.json"

Set-Location $RepoDir
conda activate diffusionposer5070
```

`$SplitDir` 必须包含 `train.txt` 和 `test.txt`。列表中的 key 是相对
`$SourceDir` 的 source 路径。

## 2. Source 转换

```powershell
python -m data_converter.amass_to_realtime_pose `
  --amass_dir "$AmassDir" `
  --smpl_model_dir "$SmplModelDir" `
  --body_fbx_rest_json "$BodyFbxRestJson" `
  --output_dir "$SourceDir" `
  --batch_size 256 `
  --num_workers 1 `
  --worker_torch_threads 1
```

Source 固定为 RPM P2 的 30Hz，包含 24 关节 world rotation/FK 相关数据和六个
Tracker 的完整测量。

## 3. 单帧 Task Store

```powershell
python -m data_loaders.generate_realtime_pose_tasks `
  --source_dir "$SourceDir" `
  --split_dir "$SplitDir" `
  --output_dir "$TaskDir" `
  --splits train test `
  --base_windows_per_source 20 `
  --shard_size 4096 `
  --seed 10
```

主字段是 `motion_context_clean [M,10,144]`、
`core_tracker_context_clean [M,11,54]`、
`current_pose_target_clean [M,144]` 和
`current_tracker_continuous [M,6,9]`。Task Store 保存原始物理值；训练
Dataset 加载时归一化，并以 1:1 交替产生 core-only 和 all-six 样本。

## 4. Normalizer

```powershell
python -m data_loaders.compute_realtime_pose_normalizer `
  --task_dir "$TaskDir" `
  --split train `
  --output_dir "$NormalizerDir"
```

应生成六个文件：

```text
pose_mean.pt
pose_scale.pt
tracker_mean.pt
tracker_std.pt
predictor_sparse_mean.pt
predictor_sparse_std.pt
```

## 5. Predictor 单阶段训练

```powershell
python -m train.train_realtime_pose_predictor `
  --source_dir "$SourceDir" `
  --split_dir "$SplitDir" `
  --normalizer_dir "$NormalizerDir" `
  --save_dir "$PredictorDir" `
  --windows_per_source 128 `
  --batch_size 64 `
  --num_steps 100000 `
  --checkpoint_max_keep 3 `
  --device 0
```

每个 batch 均匀采样 `fr in [0,30]`。前 `fr` 步为 `eval + no_grad`，每步只
回填 horizon 0，并基于当前 Head yaw 重新构造 `C_n`。默认 AdamW 为
`lr=3e-4`、`weight_decay=1e-4`，完成 50,000 步后学习率除以 30。最新 EMA 推理
权重写入 `$PredictorDir\model_latest.pt`；每次保存生成同 step 的
model/EMA/optimizer 三件套。`checkpoint_max_keep=3` 只保留最近 3 组，设为 0
表示全部保留；恢复训练使用 `--resume_checkpoint latest`。

## 6. Predictor 独立长序列评估

```powershell
$PredictorReport = Join-Path $ArtifactRoot "output\predictor_longseq_report.json"

python -m eval.evaluate_realtime_pose_predictor `
  --source_dir "$SourceDir" `
  --split_dir "$SplitDir" `
  --split test `
  --normalizer_dir "$NormalizerDir" `
  --predictor_model_path (Join-Path $PredictorDir "model_latest.pt") `
  --output_json "$PredictorReport" `
  --device 0
```

该入口不加载 DiT，报告 current rotation、MPJPE、11 帧 horizon 和前 30/后续
闭环 rotation error。

## 7. IK confidence 校准

```powershell
python -m eval.calibrate_realtime_pose_ik `
  --data_dir "$TaskDir" `
  --normalizer_dir "$NormalizerDir" `
  --predictor_model_path (Join-Path $PredictorDir "model_latest.pt") `
  --output "$IKCalibration" `
  --device 0
```

校准使用冻结 Predictor current 作为 IK 初始 Pose，输出 direction-only quality 和
residual scale。

## 8. 单帧 DiT 训练

```powershell
python -m train.train_diffusionposer `
  --model_arch current_dit `
  --data_dir "$TaskDir" `
  --data_split train `
  --normalizer_dir "$NormalizerDir" `
  --predictor_model_path (Join-Path $PredictorDir "model_latest.pt") `
  --ik_calibration_path "$IKCalibration" `
  --save_dir "$DiTRunDir" `
  --run_name "main" `
  --batch_size 64 `
  --num_steps 1000000 `
  --gradient_clip `
  --device 0
```

DiT diffusion state 始终是 `[B,144]`。Predictor 使用 `eval()`、
`requires_grad=False` 和 `torch.no_grad()`；DiT checkpoint 不包含 Predictor 权重。
Predictor 与 DiT 直接读取同一份干净 10 帧历史，不添加人工历史扰动；时间误差由
Predictor 单阶段的 0～30 步闭环训练负责。

## 9. 长序列评估

```powershell
$DiTModel = Join-Path $DiTRunDir "<run>\model000100000.pt"
$Report = Join-Path $ArtifactRoot "output\longseq_report.json"

python -m sample.evaluate_longseq_eval_set `
  --source_dir "$SourceDir" `
  --split_dir "$SplitDir" `
  --split test `
  --normalizer_dir "$NormalizerDir" `
  --predictor_model_path (Join-Path $PredictorDir "model_latest.pt") `
  --dit_model_path "$DiTModel" `
  --output_json "$Report" `
  --device 0
```

序列 0～10 帧只用于 GT burn-in，不计入指标。从第 11 帧起，组合链路的
Pose history 只回填 DiT deployed 输出。报告只计算一次全局 Predictor-only
基线，并包含 8 种静态 Tracker 组合的 DiT raw 和 DiT deployed 指标。
