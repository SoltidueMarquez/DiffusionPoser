# 实时稀疏追踪姿态重建算法

本文聚焦实时稀疏追踪姿态重建的方法本身。系统以过去一秒的部署姿态、动态 Tracker 状态和 Head 运动为条件，生成当前帧 24 个关节的完整旋转，并通过确定性几何解析恢复世界空间人体状态。

方法的核心不是把缺失 Tracker 简单置零，而是显式建模“测量是否存在、是否可靠、可靠了多久”，再把可靠性感知观测与历史运动放入同一个因果时空扩散网络。模型对 10 个历史锚点和当前帧组成的完整姿态窗口联合去噪，并在 DDIM 过程中持续投影合法旋转与稳定 Tracker 旋转，从而形成一条兼顾生成能力、时间一致性与部署约束的在线重建链路。

---

## 1. 问题定义与方法概览

### 1.1 在线姿态重建

在在线帧 \(n\)，六个固定 Tracker 槽位为：

\[
\mathcal S=
\{Head,\ Left\ Wrist,\ Right\ Wrist,\ Hip,\ Left\ Foot,\ Right\ Foot\}.
\]

槽位固定不等于六个 Tracker 始终可用。除 Head 外，其余 Tracker 可以未配置、测量掉线或重新连接。Head 始终有效，用于定义当前参考系和最终世界空间锚点。

系统保留最近 60 帧密集历史，并使用时间偏移序列：

\[
T=
(t_0,t_1,\ldots,t_{10})
=
(-60,-53,-47,-40,-34,-27,-21,-14,-8,-1,0).
\]

窗口槽位 \(s\in\{0,\ldots,10\}\) 对应的真实帧为 \(n+t_s\)。前 10 个槽位是历史锚点，\(s=10\) 是当前帧。

令 \(X_{n,0}\in\mathbb R^{11\times144}\) 表示在线帧 \(n\) 对应的干净姿态窗口。模型学习：

\[
p_\theta\!\left(
X_{n,0}
\mid
C_n
\right),
\]

其中完整条件集合定义为：

\[
C_n=
\{H_n,O_n,P_n,G_n,M_n,T\}.
\]

| 变量 | 含义 |
|---|---|
| \(X_{n,0}\in\mathbb R^{11\times144}\) | 10 个历史锚点和当前帧组成的干净姿态窗口 |
| \(H_n\in\mathbb R^{10\times144}\) | 独立历史姿态序列 |
| \(O_n\in\mathbb R^{11\times6\times13}\) | 同步 Tracker 观测序列 |
| \(P_n\in\mathbb R^{11\times5}\) | Head 在当前参考系中的非增量路径 |
| \(G_n\in\mathbb R^{10\times5}\) | 历史姿态的区域可信度序列 |
| \(M_n\in\{0,1\}^{11}\) | 冷启动窗口有效性序列 |
| \(T\in\mathbb Z^{11}\) | 固定真实帧偏移序列 |

Projected DDIM 输出完整 deployed 窗口 \(\tilde X_{n,0}\)，系统只发布当前槽位：

\[
\tilde x_n
=
\left[\tilde X_{n,0}\right]_{s=10}
\in\mathbb R^{144}.
\]

\(\tilde x_n\) 由 24 个关节在当前参考系中的全局 rotation6D 组成。Actor Root 平移不进入生成目标，而由 Head-anchored resolver 解析得到。

### 1.2 符号约定

本文使用“大写表示序列或多元素张量，小写表示单帧、单节点或单元素”的规则：

\[
X_n=(x_{n,0},\ldots,x_{n,10}),
\qquad
O_n=(o_{n,s,i})_{s,i}.
\]

主要索引约定为：

| 索引 | 含义 |
|---|---|
| \(n\) | 当前在线帧 |
| \(s\) | 窗口槽位，\(s=0,\ldots,10\) |
| \(n+t_s\) | 槽位 \(s\) 对应的真实帧 |
| \(k\) | 扩散时间步 |
| \(l\) | DiT block 编号 |
| \(b\) | batch 样本编号 |
| \(i\) | Tracker 编号 |
| \(j\) | 关节编号 |
| \(r\) | 身体区域编号 |

旋转矩阵 \(R\)、线性映射 \(W\)、Attention 的 \(Q/K/V\)、集合 \(\mathcal S\) 和投影算子 \(\mathcal P\) 保留标准大写记法。上标 \(\mathrm{pos}\)、\(\mathrm{rot}\)、\(\mathrm{hist}\)、\(\mathrm{net}\)、\(\mathrm{proj}\) 只表示语义类别，不表示乘方。

### 1.3 核心困难与对应设计

| 核心困难 | 直接影响 | 方法设计 |
|---|---|---|
| Tracker 配置和有效性随时间变化 | 相同的零测量可能表示未配置、掉线或冷启动 | 显式状态通道、持续时间、连续可靠度与 hard gate |
| 当前稀疏测量不能唯一决定全身姿态 | 欠观测区域容易产生不协调运动 | 历史姿态条件与因果 Temporal Attention |
| 一秒历史直接逐帧建模成本较高 | 时间上下文与计算量冲突 | 60 帧密集缓存与 10 个非均匀锚点 |
| rotation6D 与 Tracker 约束不天然严格满足 | 生成结果可能不合法或偏离稳定测量 | SO(3) projection 与 Projected DDIM |
| 局部姿态生成与世界 Root 恢复耦合 | 网络同时学习旋转和平移会增加歧义 | Head-yaw 参考系与确定性世界解析 |

### 1.4 总体架构

~~~mermaid
flowchart LR
    HISTORY["过去 60 帧部署历史"] --> ANCHOR["固定抽取 10 个历史锚点"]
    CURRENT["当前 Tracker 与状态"] --> WINDOW["构造 10+1 同步窗口"]
    ANCHOR --> WINDOW

    REF --> HEADPATH["Head path 与真实帧偏移"]

    POSE --> CONDITION["时空条件 token"]
    HEADPATH --> CONDITION
    RELIABILITY --> CONDITION

    NOISE["11×144 高斯噪声"] --> DIT["因子化 SpatioTemporal DiT"]
    CONDITION --> DIT
    DIT --> NET["Network clean-pose window"]
    NET --> PROJECTION["SO(3) 与当前 hard rotation projection"]
    RELIABILITY --> PROJECTION
    PROJECTION --> DDIM["Projected DDIM 更新"]
    DDIM -->|"下一去噪步"| DIT
~~~

**图 1：总体算法。** 历史姿态、Tracker 窗口和 Head 路径共同进入同一个时空 token 网格；运动先验由因果时间注意力从历史 token 中隐式形成，不再依赖独立的运动编码器。

### 1.5 方法的五个关键机制

1. **统一当前参考系。** 全部历史锚点和当前帧在构造输入时统一变换到当前 \(F_n\)，避免窗口混合多个局部坐标系。
2. **可靠性感知动态观测。** 用 configured、measured、d_on 和 d_off 区分设备状态，并用可靠度 \(w\) 与区域覆盖度 \(a\) 连续控制测量影响。
3. **因子化时空建模。** 每层依次执行 Tracker cross-attention、关节空间注意力和同关节因果时间注意力。
4. **Soft-Hard 约束分工。** 恢复期测量以 soft 条件参与生成，稳定旋转以 hard projection 严格满足。
5. **Head-anchored 世界解析。** 网络只生成旋转，Root 平移和 Pelvis 高度由 Head 观测与骨架 FK 解析恢复。

## 2. 时空表示

### 2.1 当前 Head-yaw 参考系

世界坐标系记为 \(W\)，当前 Head-yaw 参考系记为 \(F_n\)。其原点位于当前 Head 的水平位置和地面高度：

\[
o_n^W=
\begin{bmatrix}
p^W_{H,n,x} & y_{floor} & p^W_{H,n,z}
\end{bmatrix}^{\!\top}.
\]

令 \(R^W_{F_n}=R_y(\psi^W_{H,n})\) 表示从 \(F_n\) 到 \(W\) 的 Head yaw 旋转。槽位 \(s\) 对应真实帧 \(n+t_s\)，其关节旋转和 Tracker 变换统一写为：

\[
R^{F_n}_{n,s,j}
=
(R^W_{F_n})^\top
R^W_{n+t_s,j},
\]

\[
p^{F_n}_{n,s,i}
=
(R^W_{F_n})^\top
\left(
p^W_{n+t_s,i}-o_n^W
\right),
\qquad
R^{F_n}_{n,s,i}
=
(R^W_{F_n})^\top
R^W_{n+t_s,i}.
\]

Pose、Tracker 和 Head path 的全部 11 个节点都使用同一个当前参考系 \(F_n\)。因此，同一个历史世界姿态在不同在线帧中会得到不同的局部表示 \(x_{n,s}\)。

当 Head forward 轴的水平投影接近零时，Head yaw 沿用上一帧合法值，以避免参考系在俯仰接近竖直时退化。

### 2.2 非均匀历史锚点

过去一秒的密集历史索引为 \(0,\ldots,59\)，当前帧索引为 60。时间偏移序列 \(T\) 对应的缓存索引为：

\[
(0,7,13,20,26,33,39,46,52,59,60).
\]

这种采样在固定 11 个时间节点下同时保留：

- 接近一秒的长时运动趋势；
- 当前帧附近的短时变化；
- 可控的时空注意力计算量。

偏移值 \(t_s\) 通过 sinusoidal embedding 注入模型，因此时间注意力不会把非均匀锚点误认为等间隔采样。

冷启动时，设可见密集历史长度为 \(L_n^{hist}\in[0,60]\)，其在 61 帧缓存中的起始位置为：

\[
u_n=60-L_n^{hist}.
\]

窗口有效性序列 \(M_n=(m_{n,0},\ldots,m_{n,10})\) 定义为：

\[
m_{n,s}
=
\mathbb 1[60+t_s\ge u_n],
\qquad s=0,\ldots,9,
\]

且当前槽位恒有 \(m_{n,10}=1\)。无效槽位清零，并被禁止作为 Temporal Attention key。

### 2.3 144D 姿态窗口

每个槽位的姿态由 24 个关节在 \(F_n\) 中的全局 rotation6D 拼接：

\[
x_{n,s}
=
\operatorname{Concat}_{j=1}^{24}
r^{6D,F_n}_{n,s,j}
\in\mathbb R^{144}.
\]

完整干净姿态窗口为：

\[
X_{n,0}
=
(x_{n,0},x_{n,1},\ldots,x_{n,10})
\in\mathbb R^{11\times144}.
\]

这里第二个下标 0 表示 clean diffusion state，而不是窗口槽位。历史姿态序列独立写为：

\[
H_n
=
(h_{n,0},h_{n,1},\ldots,h_{n,9}),
\qquad
h_{n,s}=x_{n,s}.
\]

训练时可以单独扰动 \(H_n\)，但扩散监督 \(X_{n,0}\) 保持干净。在线推理时，\(h_{n,s}\) 来自过去 deployed 预测在当前 \(F_n\) 中的重新表达，而不是未来真值。

### 2.4 13D Tracker 表示

第 \(i\) 个 Tracker 在槽位 \(s\) 的单节点观测为：

\[
o_{n,s,i}
=
\left[
p^{F_n}_{n,s,i},
r^{6D,F_n}_{n,s,i},
c_{n,s,i},
v_{n,s,i},
\bar d^{off}_{n,s,i},
\bar d^{on}_{n,s,i}
\right]
\in\mathbb R^{13}.
\]

其中：

- \(p^{F_n}_{n,s,i}\in\mathbb R^3\) 是位置；
- \(r^{6D,F_n}_{n,s,i}\in\mathbb R^6\) 是旋转；
- \(c_{n,s,i}\in\{0,1\}\) 表示是否配置；
- \(v_{n,s,i}\in\{0,1\}\) 表示测量是否有效；
- \(d^{off}\) 和 \(d^{on}\) 分别表示连续掉线与连续有效时长。

持续时间按上限 \(D_{cap}\) 归一化：

\[
\bar d^{state}_{n,s,i}
=
\frac{
\min(d^{state}_{n,s,i},D_{cap})
}{D_{cap}},
\qquad
state\in\{\mathrm{off},\mathrm{on}\}.
\]

完整 Tracker 观测序列记为 \(O_n=(o_{n,s,i})_{s,i}\)。无效测量的 position 和 rotation 严格清零，但状态与持续时间保留。因此，模型能区分“没有设备”和“设备存在但当前没有测量”。

### 2.5 5D Head 路径

Head path 的单节点 \(p^{head}_{n,s}\) 表示真实帧 \(n+t_s\) 相对当前 Head 原点和当前 yaw 的非增量状态：

\[
p^{head}_{n,s}
=
\left[
x^{F_n}_{H,n,s},
z^{F_n}_{H,n,s},
h^{head}_{n,s},
\sin(\psi^W_{H,n+t_s}-\psi^W_{H,n}),
\cos(\psi^W_{H,n+t_s}-\psi^W_{H,n})
\right]
\in\mathbb R^5,
\]

其中：

\[
h^{head}_{n,s}
=
p^W_{H,n+t_s,y}-y_{floor}.
\]

当前节点恒为：

\[
p^{head}_{n,10}
=
[0,0,h^{head}_{n,10},0,1].
\]

完整 Head 路径记为 \(P_n=(p^{head}_{n,0},\ldots,p^{head}_{n,10})\)。它不是相邻锚点的位移增量，而是各节点相对当前时刻的路径状态，同时提供全身平移趋势、转向趋势和人体高度信息。

### 2.6 核心张量

设 \(N_{batch}\) 为 batch size，\(d_{model}\) 为 DiT latent dimension。

| 张量 | 形状 | 算法语义 |
|---|---:|---|
| \(X_{n,k}\) | \([N_{batch},11,144]\) | 扩散步 \(k\) 的姿态窗口 |
| \(H_n\) | \([N_{batch},10,144]\) | 过去 deployed 姿态条件序列 |
| \(O_n\) | \([N_{batch},11,6,13]\) | 同步动态观测序列 |
| \(P_n\) | \([N_{batch},11,5]\) | 当前参考系中的 Head 路径 |
| \(G_n\) | \([N_{batch},10,5]\) | 五个身体区域的历史可信度序列 |
| \(M_n\) | \([N_{batch},11]\) | 冷启动有效性序列 |
| \(T\) | \([11]\) 或 \([N_{batch},11]\) | 真实帧偏移序列 |
| \(Z^{(l)}\) | \([N_{batch},11,24,d_{model}]\) | 第 \(l\) 层时空 token 网格 |
| \(\hat X^{net}_{n,0\mid k}\) | \([N_{batch},11,144]\) | 网络在扩散步 \(k\) 预测的 clean window |
| \(\tilde x_n\) | \([N_{batch},144]\) | 最终发布的当前帧 deployed pose |

## 3. 可靠性感知动态观测

### 3.1 Tracker 状态演化

Tracker 状态满足：

| 状态 | \(c\) | \(v\) | 持续时间语义 |
|---|---:|---:|---|
| 未配置 | 0 | 0 | \(d^{off}=d^{on}=0\) |
| 已配置但掉线 | 1 | 0 | \(d^{off}\) 连续增加 |
| 已配置且有效 | 1 | 1 | \(d^{on}\) 连续增加 |

在当前在线帧 \(n\)，持续时间递推为：

\[
d^{on}_{n,i}
=
\begin{cases}
\min(d^{on}_{n-1,i}+1,D_{cap}),
& c_{n,i}v_{n,i}=1,\\
0,
& \text{otherwise},
\end{cases}
\]

\[
d^{off}_{n,i}
=
\begin{cases}
\min(d^{off}_{n-1,i}+1,D_{cap}),
& c_{n,i}=1,\ v_{n,i}=0,\\
0,
& \text{otherwise}.
\end{cases}
\]

持续时间从当前在线会话起点累计。这样，冷启动和重连都具有明确的时间语义。

窗口槽位中的持续时间继承对应真实帧的状态：

\[
d^{state}_{n,s,i}
=
d^{state}_{n+t_s,i},
\qquad
state\in\{\mathrm{off},\mathrm{on}\}.
\]

### 3.2 单 Tracker 可靠度

位置和旋转分别计算 soft 可靠度权重：

\[
w^{type}_{n,s,i}
=
c_{n,s,i}v_{n,s,i}
\min\!\left(
1,
\frac{d^{on}_{n,s,i}}{D^{type}_{warm}}
\right),
\qquad
type\in\{\mathrm{pos},\mathrm{rot}\}.
\]

\(w^{type}\in[0,1]\) 表示测量从“不可用”到“稳定可信”的连续过渡：

- 未配置或掉线时，\(w^{type}=0\)；
- 刚重连时，\(w^{type}\) 从小值逐渐增加；
- 连续有效达到 warm-up 后，\(w^{type}=1\)。

这种设计避免重连测量在单帧内从完全无效跳变为完全可信。

### 3.3 区域覆盖度

24 个关节划分为五个目标区域：

| 区域 | 关节 |
|---|---|
| torso | Pelvis、Spine1、Spine2、Spine3、Neck、Head、左右 Collar |
| left arm | Left Shoulder、Left Elbow、Left Wrist、Left Hand |
| right arm | Right Shoulder、Right Elbow、Right Wrist、Right Hand |
| left leg | Left Hip、Left Knee、Left Ankle、Left Foot |
| right leg | Right Hip、Right Knee、Right Ankle、Right Foot |

Tracker 对区域的固定覆盖关系为：

| 区域 | Position Tracker | Rotation Tracker |
|---|---|---|
| torso | Hip | Head、Hip |
| left arm | Left Wrist | Left Wrist |
| right arm | Right Wrist | Right Wrist |
| left leg | Left Foot | Left Foot |
| right leg | Right Foot | Right Foot |

设 \(A^{type}_{r,i}\in\{0,1\}\) 表示 Tracker \(i\) 是否覆盖区域 \(r\) 的观测类型 \(type\)，则单节点区域覆盖度为：

\[
a^{type}_{n,s,r}
=
1-
\prod_i
\left(
1-A^{type}_{r,i}w^{type}_{n,s,i}
\right).
\]

\(a^{type}=0\) 表示区域没有直接证据，\(a^{type}=1\) 表示至少存在完全可靠的覆盖。Noisy-OR 允许多个 Tracker 对同一区域共同提供证据。

### 3.4 Soft 条件与 hard gate

Soft 权重控制测量如何进入网络；hard gate 决定当前旋转是否可以被严格替换：

\[
e^{rot}_{n,i}
=
c_{n,10,i}v_{n,10,i}
\mathbb 1
[d^{on}_{n,10,i}\ge D_h].
\]

Head 是当前参考系和世界解析锚点，因此始终满足：

\[
e^{rot}_{n,Head}=1.
\]

其余 Tracker 只有在连续稳定后进入 hard 集合。由此形成明确分工：

| 测量状态 | 网络条件 | Hard projection |
|---|---|---|
| 无效 | 不读取 position / rotation | 不启用 |
| 恢复期 | 按 \(w^{type}\) 逐渐增强 | 不启用 |
| 稳定期 | 完全读取 | 当前旋转严格替换 |

### 3.5 逐帧观测编码

对每个窗口槽位，Window Observation Encoder 分别产生三类 token 序列：

\[
E^{state}
\in
\mathbb R^{N_{batch}\times11\times6\times d_{model}},
\]

\[
E^{pos}
\in
\mathbb R^{N_{batch}\times11\times5\times d_{model}},
\]

\[
E^{rot}
\in
\mathbb R^{N_{batch}\times11\times6\times d_{model}}.
\]

三类 token 分别回答：

| Token | 回答的问题 |
|---|---|
| State | Tracker 是否配置、是否有效、已掉线或恢复多久 |
| Position | 当前有哪些区域位置证据 |
| Rotation | 当前有哪些区域朝向证据 |

每个 Tracker token 加入身份 embedding。State token 对全部关节可见；Position 和 Rotation token 通过区域覆盖关系与可靠度路由。

观测编码保持完整时间轴，不把历史压缩为单个向量。不同锚点的观测变化随后通过 Temporal Attention 进入当前姿态。

### 3.6 历史区域可信度

历史槽位 \(s=0,\ldots,9\) 的区域可信度定义为：

\[
g^{hist}_{n,s,r}
=
\frac{
a^{pos}_{n,s,r}
+
a^{rot}_{n,s,r}
}{2}.
\]

完整历史可信度序列记为：

\[
G_n
=
\left(g^{hist}_{n,s,r}\right)_{s=0,\ldots,9;\ r=1,\ldots,5}.
\]

该值同时用于：

1. 缩放历史 Pose token；
2. 调整历史姿态扰动强度；
3. 降低低观测区域的错误历史对当前预测的影响。

因此，历史姿态不是无条件可信的“真值先验”，而是带有区域可信度的闭环状态。

## 4. 因子化时空 DiT

### 4.1 历史姿态条件

将 batch 中的历史姿态恢复为 \([N_{batch},10,24,6]\)。单个历史关节状态 \(h_{b,s,j}\in\mathbb R^6\) 独立映射到 latent：

\[
e^{pose}_{b,s,j}
=
W_{pose}
h_{b,s,j}
\cdot
g^{hist}_{b,s,r(j)}.
\]

完整历史 Pose token 序列记为 \(E^{pose}=(e^{pose}_{b,s,j})_{b,s,j}\)。令 \(\bar e^{pose}_{b,s,j}\) 表示补零后序列 \(\bar E^{pose}\) 中的单个 token。

当前节点没有历史姿态条件，因此在时间轴末尾追加零 token：

\[
\bar E^{pose}
=
\operatorname{Concat}_s
(E^{pose},0_{current})
\in
\mathbb R^{N_{batch}\times11\times24\times d_{model}}.
\]

这一设计保证当前真值不会通过历史分支泄漏给模型。

### 4.2 Head path 与时间位置条件

每个 5D Head path 节点 \(p^{head}_{b,s}\) 经 MLP 编码为 \(e^{head}_{b,s}\)。不同身体区域使用固定强度 \(u^{head}_r\)：

| torso | left arm | right arm | left leg | right leg |
|---:|---:|---:|---:|---:|
| 1.0 | 0.25 | 0.25 | 1.0 | 1.0 |

因此：

\[
\bar e^{head}_{b,s,j}
=
u^{head}_{r(j)}e^{head}_{b,s}.
\]

真实帧偏移 \(t_s\) 编码为 \(e^{time}_{b,s}\)。单个时空位置的静态条件 token 为：

\[
e^{cond}_{b,s,j}
=
\bar e^{pose}_{b,s,j}
+
\bar e^{head}_{b,s,j}
+
e^{time}_{b,s}.
\]

Head path 对 torso 和双腿影响更强，使转向、行进和高度变化主要控制身体主体与支撑链；手臂保留更大的独立运动自由度。

### 4.3 初始 token

带噪姿态窗口 \(X_{n,k}\) 重排为 \([N_{batch},11,24,6]\)。令 \(x_{b,k,s,j}\in\mathbb R^6\) 表示其中一个带噪关节状态，则初始 token 为：

\[
z^{(0)}_{b,s,j}
=
W_x\,x_{b,k,s,j}
+
e^{joint}_j
+
e^{region}_{r(j)}
+
e^{cond}_{b,s,j}.
\]

完整初始 token 网格记为 \(Z^{(0)}=(z^{(0)}_{b,s,j})_{b,s,j}\)。

其中：

- \(W_x\) 编码带噪 rotation6D；
- \(e^{joint}\) 区分 24 个关节；
- \(e^{region}\) 提供身体区域身份；
- \(e^{cond}\) 注入历史 Pose、Head path 和真实时间偏移。

扩散时间 \(k\) 通过每个 block 的 AdaLN-Zero 调制进入网络。

### 4.4 Block 结构

每个 SpatioTemporal DiT block 依次执行：

~~~text
同帧 Tracker cross-attention
    -> 同帧 24 关节 Spatial Self-Attention
    -> 同关节 11 节点 Causal Temporal Self-Attention
    -> Token-wise MLP
~~~

这种因子化结构把 \(11\times24\) 时空网格分解为两个明确子问题：

- Spatial Attention 学习同一帧的全身骨架协调；
- Temporal Attention 学习同一关节跨不同时间尺度的运动连续性。

### 4.5 可靠性感知 Tracker cross-attention

第 \(l\) 个 block 的共同 query 网格为：

\[
Q^{(l)}
=
\operatorname{LN}_{cond}
\left(
Z^{(l)}
\right).
\]

三个观测分支为：

\[
U^{state}
=
\operatorname{Attn}
(Q^{(l)},E^{state},E^{state}),
\]

\[
U^{pos}
=
\operatorname{Attn}
(Q^{(l)},E^{pos},E^{pos};B^{pos}),
\]

\[
U^{rot}
=
\operatorname{Attn}
(Q^{(l)},E^{rot},E^{rot};B^{rot}).
\]

Position 和 Rotation 的 attention bias 为：

\[
B^{type}_{b,s,j,i}
=
\begin{cases}
\log\max(w^{type}_{b,s,i},10^{-6}),
&
A^{type}_{r(j),i}=1,\quad
w^{type}_{b,s,i}>0,\\
-\infty,
&
\text{otherwise}.
\end{cases}
\]

其中 Position 分支只使用五个非 Head Tracker，Rotation 分支使用全部六个 Tracker。

令 \(u^{type}_{b,s,j}\) 表示 \(U^{type}\) 中的单个输出 token。当目标区域完全没有该类观测时，显式定义：

\[
a^{type}_{b,s,r(j)}=0
\quad\Longrightarrow\quad
u^{type}_{b,s,j}=0.
\]

该定义避免“全部 attention key 都为 \(-\infty\)”造成数学上的未定义 Softmax。

条件写回为：

\[
\bar z^{(l)}_{b,s,j}
=
z^{(l)}_{b,s,j}
+
u^{state}_{b,s,j}
+
a^{pos}_{b,s,r(j)}
u^{pos}_{b,s,j}
+
a^{rot}_{b,s,r(j)}
u^{rot}_{b,s,j}.
\]

这里存在两级可靠度控制：

1. \(\log w\) 在 key 侧影响多个 Tracker 之间的 attention 权重；
2. \(a\) 在输出侧控制该观测类型对整个目标区域的写入强度。

### 4.6 Spatial Self-Attention

空间分支先把 cross-attention 后的 token 重排为：

\[
Z^{space,in}
\in
\mathbb R^{(N_{batch}\cdot11)\times24\times d_{model}}.
\]

扩散时间 embedding \(e_k\) 产生 AdaLN shift、scale 与 residual gate：

\[
Q^{space}
=
\operatorname{AdaLN}
\left(
\operatorname{LN}_{space}
(Z^{space,in});
e_k
\right),
\]

\[
Z^{space,out}
=
Z^{space,in}
+
g_{space}(e_k)
\operatorname{SelfAttn}
(Q^{space}).
\]

该分支允许手腕证据沿手臂链传播，允许 Hip 和 Foot 证据共同约束支撑姿态，并保持躯干与四肢的全身协调。

### 4.7 Causal Temporal Self-Attention

时间分支把 \(Z^{space,out}\) 重排为：

\[
Z^{time,in}
\in
\mathbb R^{(N_{batch}\cdot24)\times11\times d_{model}}.
\]

允许关系为：

\[
M^{allow}_{b,s,s'}
=
\mathbb 1[s'\le s]
m_{b,s'}.
\]

历史节点不能读取未来锚点或当前帧；当前节点可以读取全部有效历史和自身。时间更新为：

\[
Q^{time}
=
\operatorname{AdaLN}
\left(
\operatorname{LN}_{time}
(Z^{time,in});
e_k
\right),
\]

\[
Z^{time,out}
=
Z^{time,in}
+
g_{time}(e_k)
\operatorname{SelfAttn}
(Q^{time};M^{allow}).
\]

由于每个历史节点已经经过同帧空间注意力，当前关节读取到的不只是该关节的原始历史，而是带有历史全身上下文的同关节表示。

### 4.8 MLP 与输出

Block 最后执行：

\[
Z^{(l+1)}
=
Z^{time,out}
+
g_{mlp}(e_k)
\operatorname{MLP}
\left(
\operatorname{AdaLN}
(
\operatorname{LN}_{mlp}
(Z^{time,out});
e_k
)
\right).
\]

最终输出为：

\[
\hat X^{net}_{n,0\mid k}
\in
\mathbb R^{N_{batch}\times11\times144}.
\]

当前时间节点还产生两个辅助输出：

| 输出 | 形状 | 语义 |
|---|---:|---|
| Future-leg | \([N_{batch},3,8,6]\) | 未来 3 帧、8 个腿部关节的 rotation6D |
| Contact | \([N_{batch},2]\) | 当前左右脚接触 logits |

辅助头提供短期腿部趋势和支撑状态监督，但不直接修改扩散状态。

## 5. Projected DDIM

### 5.1 完整窗口扩散

对完整姿态窗口执行前向扩散：

\[
X_k
=
\sqrt{\bar\alpha_k}X_0
+
\sqrt{1-\bar\alpha_k}\,
\epsilon,
\qquad
\epsilon\sim\mathcal N(0,I).
\]

同一个扩散时间步 \(k\) 作用于一个样本的完整 11 帧窗口。无效冷启动节点在加噪后重新清零。

模型采用 \(x_0\)-prediction：

\[
\hat X_{0,k}^{raw}
=
f_\theta
(X_k,k,\mathcal C_n).
\]

历史姿态不是固定 inpainting 区域。模型既读取独立历史条件，也以较低权重重建历史窗口，从而学习一个完整的时空 clean-pose 分布。

### 5.2 SO(3) 与 hard rotation projection

定义投影算子：

\[
\hat X_{0,k}^{proj}
=
\mathcal P_R
\left(
\hat X_{0,k}^{raw};
O_n^{R,raw},
h_n^R
\right).
\]

投影依次执行：

1. 将标准化预测恢复到物理 rotation6D 空间；
2. 对全部 11 帧、24 个关节执行稳定 Gram-Schmidt；
3. 对当前帧 hard Tracker 对应关节执行全局旋转替换；
4. 重新编码为 rotation6D 并回到扩散空间。

Tracker 与关节的固定对应关系为：

| Tracker | Head | Left Wrist | Right Wrist | Hip | Left Foot | Right Foot |
|---|---|---|---|---|---|---|
| Joint | Head | Left Wrist | Right Wrist | Pelvis | Left Foot | Right Foot |

只有旋转进入 hard projection。位置测量仍以 soft 条件和几何损失参与，因为严格满足位置需要额外 IK 或约束优化。

### 5.3 用 projected \(x_0\) 推进采样

当前 step 真正采用的 clean-pose estimate 为：

\[
\bar X_{0,k}
=
\begin{cases}
\hat X_{0,k}^{proj},
& \text{该 step 启用投影},\\
\hat X_{0,k}^{raw},
& \text{该 step 不启用投影}.
\end{cases}
\]

由 \(\bar X_{0,k}\) 重新计算噪声：

\[
\epsilon_k
=
\frac{
X_k
-
\sqrt{\bar\alpha_k}
\bar X_{0,k}
}{
\sqrt{1-\bar\alpha_k}
}.
\]

DDIM 更新为：

\[
\sigma_k
=
\eta
\sqrt{
\frac{
1-\bar\alpha_{k-1}
}{
1-\bar\alpha_k
}
}
\sqrt{
1-
\frac{
\bar\alpha_k
}{
\bar\alpha_{k-1}
}
},
\]

\[
X_{k-1}
=
\sqrt{\bar\alpha_{k-1}}
\bar X_{0,k}
+
\sqrt{
1-\bar\alpha_{k-1}-\sigma_k^2
}
\epsilon_k
+
\sigma_k z.
\]

Projected DDIM 的关键不是最终覆盖一次 Tracker 旋转，而是让投影后的 clean-pose estimate 改变后续全部去噪轨迹。

### 5.4 Algorithm 1：Projected DDIM

~~~text
输入：
    已编码的窗口条件
    当前 Tracker 原始旋转
    当前 hard rotation state
    投影模式
    DDIM 时间步集合

X_K <- [B,11,144] 高斯噪声

for k = K-1, ..., 0:
    raw_x0 <- SpatioTemporalDiT(X_k, k, conditioning)
    projected_x0 <- P_R(raw_x0)

    if 当前模式在第 k 步启用投影:
        step_x0 <- projected_x0
    else:
        step_x0 <- raw_x0

    epsilon_k <- 由 X_k 和 step_x0 重新计算

    if k > 0:
        X_{k-1} <- DDIM(step_x0, epsilon_k, k)
    else:
        final_raw_pose <- raw_x0[-1]
        deployed_pose <- projected_x0[-1]

返回 final_raw_pose、deployed_pose 与辅助输出
~~~

### 5.5 Soft-Hard 原则

方法遵循：

> 只有能够稳定、低成本并以闭式形式满足的约束进入 Hard；其余证据通过可靠性感知的 Soft conditioning 参与生成。

对应关系为：

| 信息 | 处理方式 |
|---|---|
| Tracker 状态 | State conditioning |
| 恢复期 position / rotation | Reliability-aware soft conditioning |
| 历史姿态与 Head path | 时空条件 |
| 合法旋转 | 全窗口 SO(3) projection |
| 稳定 Tracker rotation | 当前帧 hard replacement |
| Tracker position | Soft condition 与几何损失 |
| Root 平移 | Head-anchored deterministic resolver |

## 6. 训练目标

### 6.1 加权窗口重建

完整 11 帧窗口参与扩散监督。先定义每个有效节点的 144D 平均重建误差：

\[
\ell_t
=
\frac{1}{144}
\sum_{d=1}^{144}
\ell
\left(
\hat X^{raw}_{0,k,t,d},
X_{0,t,d}
\right).
\]

令有效历史节点集合为：

\[
\mathcal T_n
=
\{t\mid 0\le t<10,\ V_t=1\}.
\]

有效历史的平均误差为：

\[
\ell_{hist}
=
\begin{cases}
\dfrac{1}{|\mathcal T_n|}
\sum_{t\in\mathcal T_n}\ell_t,
& |\mathcal T_n|>0,\\
0,
& |\mathcal T_n|=0.
\end{cases}
\]

扩散重建项为：

\[
\mathcal L_{simple}
=
\frac{
\ell_{10}
+
\lambda_{hist}
\mathbb 1[|\mathcal T_n|>0]
\ell_{hist}
}{
1+
\lambda_{hist}
\mathbb 1[|\mathcal T_n|>0]
},
\qquad
\lambda_{hist}=0.1.
\]

默认 \(\ell\) 为 MSE。这里的 0.1 是“全部有效历史平均误差”的总权重，而不是每个历史节点各自的权重；因此当前帧始终是主要优化目标。冷启动没有有效历史时，损失退化为当前帧重建误差。

### 6.2 Raw 与 deployed 监督

Raw 输出反映网络自身的生成能力；deployed 输出反映加入确定性约束后的实际结果。两条路径使用不同监督：

| 损失 | 作用结果 | 目标 |
|---|---|---|
| Global rotation | Raw | 24 个当前关节的 SO(3) 角误差 |
| Local rotation | Raw | 父子相对旋转误差 |
| Tracker rotation | Raw | 所有当前有效 Tracker 的旋转一致性 |
| FK coordinate | Deployed | Head 参考系中的关节坐标 |
| Joint distance | Deployed | 关节欧氏位置误差 |
| Tracker position | Deployed | 非 Head Tracker 的位置一致性 |
| Root yaw | Deployed | 世界 Pelvis heading |
| Head-to-Root XZ | Deployed | Head 与 Actor Root 的水平关系 |
| Future-leg | Auxiliary | 未来腿部旋转 |
| Contact | Auxiliary | 当前双脚接触 |

即使某个关节最终由 hard projection 替换，Raw 分支仍受到扩散、旋转和 Tracker rotation 监督，避免网络退化为依赖投影的无效预测器。

Tracker position 使用三维径向 Huber：

\[
\mathcal H_\beta(d)
=
\begin{cases}
\frac{d^2}{2\beta},
& d<\beta,\\
d-\frac{\beta}{2},
& d\ge\beta.
\end{cases}
\]

### 6.3 总损失

总损失写为：

\[
\mathcal L
=
\lambda_{diff}
\mathcal L_{simple}
+
\lambda_{aux}
\sum_q
\lambda_q
\mathcal L_q.
\]

其中 \(\mathcal L_q\) 汇总旋转、FK、Tracker、Root、Future-leg 和 Contact 监督。该目标同时约束：

- Raw 姿态生成质量；
- Deployed 几何一致性；
- 欠观测腿部的短期趋势；
- 支撑与接触状态。

### 6.4 历史姿态扰动

在线历史来自过去预测，而训练历史来自干净数据。为减小二者的分布差异，只对独立历史条件 \(H^{pose}\) 添加 SO(3) 扰动，不改变扩散监督 \(X_0\)。

扰动以样本级概率 \(p_{aug}=0.8\) 启用，只作用于有效历史节点。

噪声角度由历史区域可信度决定：

\[
\sigma(c)
=
\sigma_{min}
+
(1-c)
(
\sigma_{max}-\sigma_{min}
).
\]

当前范围为 \(2^\circ\) 到 \(10^\circ\)。扰动由区域共享分量和关节独立分量组成：

\[
\xi_{t,j}
=
\sigma
(
c_{t,r(j)}
)
\left(
\sqrt{\lambda_r}\,
\xi^{region}_{t,r(j)}
+
\sqrt{\lambda_j}\,
\xi^{joint}_{t,j}
\right).
\]

默认 \(\lambda_r=0.75\)、\(\lambda_j=0.25\)，分别控制区域共享误差与关节独立误差。

两类噪声沿时间相关，并按锚点真实间隔使用：

\[
\operatorname{corr}
(
\xi_t,
\xi_{t+\Delta f}
)
=
\rho^{\Delta f}.
\]

区域共享噪声模拟整条肢体或躯干的系统性部署误差，关节噪声模拟局部预测误差。

### 6.5 动态观测与冷启动训练

训练覆盖五类动态条件：

1. 持续六点；
2. 持续三点；
3. 三点切换到六点；
4. 六点切换到三点；
5. 两个非 Head Tracker 同步掉线并重连。

冷启动样本随机缩短可见历史，使模型同时学习：

- 无历史首帧；
- 部分历史；
- 完整一秒历史。

当前训练不展开多步模型 rollout。闭环误差主要通过历史姿态扰动近似，真实误差累积则在在线长序列推理中检验。

## 7. Head-Anchored 世界解析

### 7.1 Pelvis-relative FK

最终只解析 deployed 窗口的当前帧。首先将 144D pose 转换为 \(C_n\) 中的 24 个全局旋转，并从 Pelvis 旋转提取相对 Head yaw 的 root heading：

\[
\hat\psi^{C_n}_{root}.
\]

以 Pelvis 为相对位置零点，根据骨架 offset 执行 FK：

\[
q^{C_n}_{j}
=
q^{C_n}_{parent(j)}
+
R^{C_n}_{parent(j)}
o_j.
\]

当前 Head Tracker 在 \(C_n\) 中的高度为：

\[
h^{obs}_{head}.
\]

Pelvis 高度由 Head 观测与预测骨架几何解析：

\[
h_{pelvis}
=
h^{obs}_{head}
-
q^{C_n}_{Head,y}.
\]

### 7.2 Root 水平平移

令 Pelvis 的 rest offset 为 \(o_P\)。先把其纵向分量替换为解析得到的 Pelvis 高度：

\[
\bar o_P
=
\begin{bmatrix}
o_{P,x} & h_{pelvis} & o_{P,z}
\end{bmatrix}^{\!\top}.
\]

使用预测 root heading 旋转该 offset，并把它加入 Pelvis-relative FK 结果：

\[
p^{C_n}_{P,0}
=
R_y
\left(
\hat\psi^{C_n}_{root}
\right)
\bar o_P,
\qquad
\hat q^{C_n}_j
=
q^{C_n}_j
+
p^{C_n}_{P,0}.
\]

随后整体平移骨架，使预测 Head 的 XZ 与当前参考系原点对齐：

\[
t^{C_n}_{root}
=
\begin{bmatrix}
-\hat q^{C_n}_{Head,x}\\
0\\
-\hat q^{C_n}_{Head,z}
\end{bmatrix},
\qquad
\tilde q^{C_n}_j
=
\hat q^{C_n}_j
+
t^{C_n}_{root}.
\]

这一解析将 Root 水平位置绑定到观测 Head，同时保留姿态网络对身体相对 Head 几何的预测能力。解析后 \(\tilde q^{C_n}_{Head,x}=\tilde q^{C_n}_{Head,z}=0\)。

### 7.3 恢复世界结果

世界空间 Root 和关节为：

\[
p^W_{root}
=
o_n^W
+
R^W_{C_n}
t^{C_n}_{root},
\qquad
p^W_{root,y}=floor_y,
\]

\[
p^W_j
=
o_n^W
+
R^W_{C_n}
\tilde q^{C_n}_j,
\]

\[
R^W_j
=
R^W_{C_n}
R^{C_n}_j,
\]

\[
\psi^W_{root}
=
\psi^W_{head,n}
+
\hat\psi^{C_n}_{root}.
\]

Resolver 不执行 IK 或迭代优化，只使用一次 FK 和闭式对齐。它把生成问题限制在关节旋转空间，同时保证世界 Root 与 Head 观测一致。

### 7.4 Algorithm 2：单帧在线推理

~~~text
输入：
    当前六个 Tracker 世界变换
    configured 与 measured_valid
    当前 floor
    过去最多 60 帧 deployed 世界姿态与 Tracker 状态

1. 更新 d_off、d_on、κ、ρ 和 hard rotation state
2. 从密集历史抽取 10 个固定锚点
3. 将历史 Pose、Tracker 和 Head path 统一转换到当前 C_n
4. 构造历史可信度、valid mask 与真实帧偏移
5. 编码窗口条件
6. 对 [B,11,144] 执行 Projected DDIM
7. 取最后当前帧 deployed pose
8. 通过 Head-anchored resolver 恢复世界 Root 和关节
9. 将当前 deployed 世界状态写入历史

输出：
    当前 144D pose
    Actor Root position / yaw
    Pelvis height
    世界关节位置与旋转
~~~

下一帧只读取本帧 deployed 结果，不读取 Raw 结果或未来真值，因此在线链路保持严格闭环。

## 8. 算法性质与边界

### 8.1 因果性与信息边界

| 信息 | 历史节点可读 | 当前节点可读 |
|---|---:|---:|
| 同帧 Tracker | 是 | 是 |
| 同帧全身关节 | 是 | 是 |
| 更早时间节点 | 是 | 是 |
| 更晚历史锚点 | 否 | 是 |
| 当前帧 token | 否 | 是 |
| 未来帧 | 否 | 否 |
| 当前姿态真值条件 | 否 | 否 |

当前姿态真值只作为扩散监督，不进入历史条件。Temporal Attention 使用 causal mask，冷启动 padding 不作为 key，因此模型满足在线因果约束。

### 8.2 关键算法设置

| 设置 | 当前取值 |
|---|---:|
| 密集历史覆盖 | 60 帧 |
| 历史锚点 | 10 |
| 时空窗口 | 11 |
| Pose 维度 | 144 |
| 目标区域 | 5 |
| DiT latent | 512 |
| DiT blocks | 8 |
| Attention heads | 8 |
| Diffusion steps | 50 |
| Reliability warm-up | 15 帧 |
| Hard rotation 门槛 | 15 帧 |
| 历史重建权重 | 0.1 |
| 历史扰动概率 | 0.8 |

这些数值是当前方法的默认算法配置，后续应通过消融实验分别验证锚点密度、可靠度恢复长度、历史权重、投影频率和采样步数。

### 8.3 方法优势

- **动态观测语义明确。** 未配置、掉线、重连和稳定状态不再共享同一种输入表示。
- **时间与空间结构分离。** 因子化注意力以较低成本建模完整时空窗口。
- **历史可信度可解释。** 历史姿态影响由对应区域的观测覆盖度决定。
- **约束参与采样轨迹。** Projected DDIM 不只修正最终输出，而是逐步影响后续去噪。
- **生成与几何解析解耦。** 网络专注于旋转生成，世界 Root 由可解释几何恢复。
- **闭环部署一致。** 下一帧历史只使用 deployed 结果。

### 8.4 当前边界

- Head 必须始终有效，且 floor 与目标骨架参数已知。
- Position 只作为 soft 证据，不能保证所有 Tracker 位置严格满足。
- 10 个固定锚点压缩了过去一秒历史，可能丢失高频中间运动。
- 训练使用历史扰动近似闭环误差，但不直接优化多步 rollout。
- 扩散采样步数仍是精度与实时延迟之间的主要权衡。
- Hard rotation replacement 保证局部观测一致性，但不等价于完整人体动力学约束。

总体上，该方法把实时稀疏姿态重建表述为一个可靠性感知的因果时空扩散问题：动态 Tracker 提供当前证据，历史 deployed 姿态提供运动上下文，因子化时空 DiT 负责生成全身协调姿态，Projected DDIM 保证旋转可部署性，Head-anchored resolver 则完成从局部旋转到世界人体状态的确定性恢复。
