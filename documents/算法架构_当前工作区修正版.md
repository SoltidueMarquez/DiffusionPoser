# 实时稀疏追踪姿态重建算法

本文聚焦实时稀疏追踪姿态重建的方法本身。系统以过去一秒的部署姿态、动态 Tracker 状态和 Head 运动为条件，生成当前帧 24 个关节的完整旋转，并通过确定性几何解析恢复世界空间人体状态。

方法的核心不是把缺失 Tracker 简单置零，而是显式建模“测量是否存在、是否可靠、可靠了多久”，再把可靠性感知观测与历史运动放入同一个时空扩散网络。10 个历史锚点作为固定前缀条件，只有当前帧是 diffusion state；Projected DDIM 始终只更新当前 144D 姿态。这样删除了 10 帧没有部署用途的随机 diffusion latent，但是否降低抖动仍需由实验验证。

全文围绕两个主体展开。**Motion Representation** 回答“运动、稀疏观测和可靠度如何表示”；**Motion Framework** 回答“这些表示如何经过时空生成、约束投影和几何解析得到当前世界姿态”。前者定义模型可以读取的信息，后者定义信息如何被计算和优化。

---

## 1. 问题定义与方法概览

本文先定义表示，再定义计算框架，两部分的逻辑边界如下：

| 主体 | 回答的问题 | 主要产出 |
|---|---|---|
| Motion Representation | 一秒历史、当前稀疏 Tracker、Head 运动和观测可靠度如何变成统一张量 | 条件集合 \(\mathcal C_n\)、当前干净姿态目标 \(x_n\) 与投影约束状态 |
| Motion Framework | 如何利用上述表示生成、约束并解析当前全身姿态 | deployed 姿态 \(\tilde x_n\)、世界 Root 与世界关节状态 |

### 1.1 在线姿态重建

在在线帧 \(n\)，六个固定 Tracker 槽位为：

\[
\mathcal S=
\{Head,\ Left\ Wrist,\ Right\ Wrist,\ Hip,\ Left\ Foot,\ Right\ Foot\}.
\]

槽位固定不等于六个 Tracker 始终可用。除 Head 外，其余 Tracker 可以未配置、测量掉线或重新连接。Head 始终有效，用于定义当前参考系和最终世界空间锚点。

系统保留最近 60 帧密集历史，并使用时间偏移序列：

\[
T=
(t_0,t_1,\ldots,t_{10})
=
(-60,-53,-47,-40,-34,-27,-21,-14,-8,-1,0).
\]

窗口槽位 \(s\in\{0,\ldots,10\}\) 对应的真实帧为 \(n+t_s\)。前 10 个槽位是历史锚点，\(s=10\) 是当前帧。

令 \(X_n\in\mathbb R^{11\times144}\) 表示 Dataset 保存的干净监督窗口，令 \(x_n=[X_n]_{s=10}\in\mathbb R^{144}\) 表示当前干净姿态。模型学习：

\[
p_\theta\!\left(
x_n
\mid
\mathcal C_n
\right),
\]

其中完整条件集合定义为：

\[
\mathcal C_n=
\{H_n,O_n,P_n,G_n,M_n,T\}.
\]

| 变量 | 建议读法 | 含义 |
|---|---|---|
| \(p_\theta(x_n\mid\mathcal C_n)\) | p theta | 模型学习的当前姿态条件分布 |
| \(\theta\) | theta | 时空 DiT 的可学习参数 |
| \(\mathcal C_n\) | C 下标 n | 在线帧 \(n\) 的完整条件集合 |
| \(X_n\in\mathbb R^{11\times144}\) | X 下标 n | Dataset 保留的干净监督窗口；只有最后一帧是 diffusion target |
| \(x_n\in\mathbb R^{144}\) | x 下标 n | 当前帧干净姿态与 diffusion target |
| \(H_n\in\mathbb R^{10\times144}\) | H 下标 n | 独立历史姿态序列 |
| \(O_n\in\mathbb R^{11\times6\times13}\) | O 下标 n | 同步 Tracker 观测序列 |
| \(P_n\in\mathbb R^{11\times5}\) | P 下标 n | Head 在当前参考系中的非增量路径 |
| \(G_n\in\mathbb R^{10\times5}\) | G 下标 n | 历史姿态的区域可信度序列 |
| \(M_n\in\{0,1\}^{11}\) | M 下标 n | 冷启动窗口有效性序列 |
| \(T\in\mathbb Z^{11}\) | T | 固定真实帧偏移序列 |

Projected DDIM 直接输出当前 deployed 姿态：

\[
\tilde x_n
\in\mathbb R^{144}.
\]

\(\tilde x_n\) 由 24 个关节在当前参考系中的全局 rotation6D 组成。Actor Root 平移不进入生成目标，而由 Head-anchored resolver 解析得到。

### 1.2 符号约定

对于可沿时间、Tracker 或关节轴展开的数据对象，本文统一使用“大写表示序列或多元素张量，小写表示单帧、单节点或单元素”的规则：

\[
X_n=(x_{n,0},\ldots,x_{n,10}),
\qquad
H_n=(h_{n,0},\ldots,h_{n,9}),
\qquad
O_n=(o_{n,s,i})_{s,i}.
\]

主要索引约定为：

| 索引 | 含义 |
|---|---|
| \(n\) | 当前在线帧 |
| \(s\) | 窗口槽位，\(s=0,\ldots,10\) |
| \(n+t_s\) | 槽位 \(s\) 对应的真实帧 |
| \(k\) | 扩散时间步 |
| \(l\) | DiT block 编号 |
| \(b\) | batch 样本编号 |
| \(i\) | Tracker 编号 |
| \(j\) | 关节编号 |
| \(r\) | 身体区域编号 |

旋转矩阵 \(R\)、线性映射 \(W\)、Attention 的 \(Q/K/V\)、集合 \(\mathcal S\) 和投影算子 \(\mathcal P\) 保留标准大写记法。上标 \(\mathrm{pos}\)、\(\mathrm{rot}\)、\(\mathrm{hist}\)、\(\mathrm{net}\)、\(\mathrm{proj}\) 只表示语义类别，不表示乘方。

为避免旧记法中的冲突，\(\mathcal C_n\) 只表示完整条件集合，坐标参考系统一记为 \(F_n\)。此外，\(M_n\) 是长度为 11 的窗口有效性序列，\(M_n^{\mathrm{hard}}\) 是长度为 6 的当前 Tracker 旋转硬约束序列，二者不共享索引轴。

### 1.3 核心困难与对应设计

| 核心困难 | 直接影响 | 方法设计 |
|---|---|---|
| Tracker 配置和有效性随时间变化 | 相同的零测量可能表示未配置、掉线或冷启动 | 显式状态通道、持续时间、连续可靠度与 hard gate |
| 当前稀疏测量不能唯一决定全身姿态 | 欠观测区域容易产生不协调运动 | 固定历史前缀与非对称 Temporal Attention |
| 一秒历史直接逐帧建模成本较高 | 时间上下文与计算量冲突 | 60 帧密集缓存与 10 个非均匀锚点 |
| rotation6D 与 Tracker 约束不天然严格满足 | 生成结果可能不合法或偏离稳定测量 | SO(3) projection 与 Projected DDIM |
| 局部姿态生成与世界 Root 恢复耦合 | 网络同时学习旋转和平移会增加歧义 | Head-yaw 参考系与确定性世界解析 |

### 1.5 方法的五个关键机制

1. **统一当前参考系。** 全部历史锚点和当前帧在构造输入时统一变换到当前 \(F_n\)，避免窗口混合多个局部坐标系。
2. **可靠性感知动态观测。** 用 configured、measured、d_on 和 d_off 区分设备状态，并用可靠度 \(w\) 与区域覆盖度 \(a\) 连续控制测量影响。
3. **因子化时空建模。** 每层依次执行 Tracker cross-attention、关节空间注意力和同关节非对称前缀时间注意力。
4. **Soft-Hard 约束分工。** 恢复期测量以 soft 条件参与生成，稳定旋转以 hard projection 严格满足。
5. **Head-anchored 世界解析。** 网络只生成旋转，Root 平移和 Pelvis 高度由 Head 观测与骨架 FK 解析恢复。

## 2. Motion Representation（运动表示）

Motion Representation 由六类互补信息组成：姿态窗口、历史部署姿态、动态 Tracker 观测、Head 运动路径、历史区域可信度，以及时间与冷启动有效性。所有表示共享同一条 11 节点时间轴和同一个当前 Head-yaw 参考系，因此可以在后续网络中逐槽位对齐。

| 表示对象 | 序列或张量 | 单帧或单元素 | 主要内容 |
|---|---|---|---|
| 姿态窗口 | \(X_n\) | \(x_{n,s}\) | 24 个关节的全局 rotation6D |
| 历史姿态 | \(H_n\) | \(h_{n,s}\) | 过去 deployed 姿态在当前参考系中的重表达 |
| Tracker 观测 | \(O_n\) | \(o_{n,s,i}\) | position、rotation、配置状态、有效性和持续时间 |
| Head 路径 | \(P_n\) | \(p^{\mathrm{head}}_{n,s}\) | 相对当前 Head 的水平位置、高度和 yaw |
| 历史可信度 | \(G_n\) | \(g^{\mathrm{hist}}_{n,s,r}\) | 不同身体区域的历史可信程度 |
| 时间与有效性 | \(T,M_n\) | \(t_s,m_{n,s}\) | 真实帧偏移和冷启动有效槽位 |

### 2.1 统一的当前 Head-yaw 参考系

世界坐标系记为 \(W\)，当前 Head-yaw 参考系记为 \(F_n\)。其原点位于当前 Head 的水平位置和地面高度：

\[
p_n^{\mathrm{ref},W}=
\begin{bmatrix}
p^W_{\mathrm{Head},n,x} & y_{\mathrm{floor}} & p^W_{\mathrm{Head},n,z}
\end{bmatrix}^{\!\top}.
\]

令 \(R^W_{F_n}=R_y(\psi^W_{\mathrm{Head},n})\) 表示从 \(F_n\) 到 \(W\) 的 Head yaw 旋转。槽位 \(s\) 对应真实帧 \(n+t_s\)，其关节旋转和 Tracker 变换统一写为：

\[
R^{F_n}_{n,s,j}
=
(R^W_{F_n})^\top
R^W_{n+t_s,j},
\]

\[
p^{F_n}_{n,s,i}
=
(R^W_{F_n})^\top
\left(
p^W_{n+t_s,i}-p_n^{\mathrm{ref},W}
\right),
\qquad
R^{F_n}_{n,s,i}
=
(R^W_{F_n})^\top
R^W_{n+t_s,i}.
\]

| 变量 | 含义 |
|---|---|
| \(p_n^{\mathrm{ref},W}\) | 当前 Head 水平位置与地面高度共同定义的参考系原点 |
| \(p^W_{\mathrm{Head},n}\) | 当前帧 Head Tracker 的世界位置 |
| \(y_{\mathrm{floor}}\) | 当前地面在世界坐标系中的高度 |
| \(\psi^W_{\mathrm{Head},n}\) | 当前 Head 的世界 yaw |
| \(R^W_{F_n}=R_y(\psi^W_{\mathrm{Head},n})\) | 从当前参考系 \(F_n\) 旋转到世界系 \(W\) 的 yaw 旋转 |
| \(R^{F_n}_{n,s,j}\) | 槽位 \(s\) 中关节 \(j\) 在 \(F_n\) 中的全局旋转 |
| \(p^{F_n}_{n,s,i},R^{F_n}_{n,s,i}\) | 槽位 \(s\) 中 Tracker \(i\) 在 \(F_n\) 中的位置与旋转 |

Pose、Tracker 和 Head path 的全部 11 个节点都使用同一个当前参考系 \(F_n\)。因此，同一个历史世界姿态在不同在线帧中会得到不同的局部表示 \(x_{n,s}\)。

当 Head forward 轴的水平投影接近零时，Head yaw 沿用上一帧合法值，以避免参考系在俯仰接近竖直时退化。

### 2.2 非均匀历史时间表示

过去一秒的密集历史索引为 \(0,\ldots,59\)，当前帧索引为 60。时间偏移序列 \(T\) 对应的缓存索引为：

\[
(0,7,13,20,26,33,39,46,52,59,60).
\]

这种采样在固定 11 个时间节点下同时保留：

- 接近一秒的长时运动趋势；
- 当前帧附近的短时变化；
- 可控的时空注意力计算量。

偏移值 \(t_s\) 通过 sinusoidal embedding 注入模型，因此时间注意力不会把非均匀锚点误认为等间隔采样。

冷启动时，设可见密集历史长度为 \(L_n^{\mathrm{hist}}\in[0,60]\)。窗口有效性序列 \(M_n=(m_{n,0},\ldots,m_{n,10})\) 直接定义为：

\[
m_{n,s}
=
\mathbb 1
\left[
60+t_s\ge 60-L_n^{\mathrm{hist}}
\right],
\qquad s=0,\ldots,9,
\]

其中，\(L_n^{\mathrm{hist}}\) 是在线帧 \(n\) 可见的密集历史帧数，\(m_{n,s}\) 是槽位有效性，\(\mathbb 1[\cdot]\) 是条件成立时取 1、否则取 0 的指示函数。当前槽位恒有 \(m_{n,10}=1\)。无效槽位清零，并禁止被有效时间节点读取。

### 2.3 姿态与历史运动表示

每个槽位的姿态由 24 个关节在 \(F_n\) 中的全局 rotation6D 拼接：

\[
x_{n,s}
=
\operatorname{Concat}_{j=1}^{24}
r^{6D,F_n}_{n,s,j}
\in\mathbb R^{144}.
\]

完整干净姿态窗口为：

\[
X_n
=
(x_{n,0},x_{n,1},\ldots,x_{n,10})
\in\mathbb R^{11\times144}.
\]

历史姿态序列独立写为：

\[
H_n
=
(h_{n,0},h_{n,1},\ldots,h_{n,9}),
\qquad
h_{n,s}=x_{n,s}.
\]

训练时可以单独扰动 \(H_n\)，但扩散监督 \(X_n\) 保持干净。在线推理时，\(h_{n,s}\) 来自过去 deployed 预测在当前 \(F_n\) 中的重新表达，而不是未来真值。

### 2.4 动态 Tracker 观测表示

第 \(i\) 个 Tracker 在槽位 \(s\) 的单节点观测为：

\[
o_{n,s,i}
=
\left[
p^{F_n}_{n,s,i},
r^{6D,F_n}_{n,s,i},
c_{n,s,i},
v_{n,s,i},
\bar d^{\mathrm{off}}_{n,s,i},
\bar d^{\mathrm{on}}_{n,s,i}
\right]
\in\mathbb R^{13}.
\]

其中：

- \(p^{F_n}_{n,s,i}\in\mathbb R^3\) 是位置；
- \(r^{6D,F_n}_{n,s,i}\in\mathbb R^6\) 是旋转；
- \(c_{n,s,i}\in\{0,1\}\) 表示是否配置；
- \(v_{n,s,i}\in\{0,1\}\) 表示测量是否有效；
- \(d^{\mathrm{off}}\) 和 \(d^{\mathrm{on}}\) 分别表示连续掉线与连续有效时长。

持续时间按上限 \(d_{\mathrm{cap}}\) 归一化：

\[
\bar d^{\mathrm{state}}_{n,s,i}
=
\frac{
\min(d^{\mathrm{state}}_{n,s,i},d_{\mathrm{cap}})
}{d_{\mathrm{cap}}},
\qquad
\mathrm{state}\in\{\mathrm{off},\mathrm{on}\}.
\]

完整 Tracker 观测序列记为 \(O_n=(o_{n,s,i})_{s,i}\)。无效测量的 position 和 rotation 严格清零，但状态与持续时间保留。因此，模型能区分“没有设备”和“设备存在但当前没有测量”。

### 2.5 Head 运动路径表示

Head path 的单节点 \(p^{\mathrm{head}}_{n,s}\) 表示真实帧 \(n+t_s\) 相对当前 Head 原点和当前 yaw 的非增量状态：

\[
p^{\mathrm{head}}_{n,s}
=
\left[
p^{F_n}_{n,s,\mathrm{Head},x},
p^{F_n}_{n,s,\mathrm{Head},z},
h^{\mathrm{head}}_{n,s},
\sin(\psi^W_{\mathrm{Head},n+t_s}-\psi^W_{\mathrm{Head},n}),
\cos(\psi^W_{\mathrm{Head},n+t_s}-\psi^W_{\mathrm{Head},n})
\right]
\in\mathbb R^5,
\]

其中：

\[
h^{\mathrm{head}}_{n,s}
=
p^W_{\mathrm{Head},n+t_s,y}-y_{\mathrm{floor}}.
\]

当前节点恒为：

\[
p^{\mathrm{head}}_{n,10}
=
[0,0,h^{\mathrm{head}}_{n,10},0,1].
\]

完整 Head 路径记为 \(P_n=(p^{\mathrm{head}}_{n,0},\ldots,p^{\mathrm{head}}_{n,10})\)。它不是相邻锚点的位移增量，而是各节点相对当前时刻的路径状态，同时提供全身平移趋势、转向趋势和人体高度信息。

### 2.6 Tracker 状态与持续时间

Tracker 状态满足：

| 状态 | \(c\) | \(v\) | 持续时间语义 |
|---|---:|---:|---|
| 未配置 | 0 | 0 | \(d^{\mathrm{off}}=d^{\mathrm{on}}=0\) |
| 已配置但掉线 | 1 | 0 | \(d^{\mathrm{off}}\) 连续增加 |
| 已配置且有效 | 1 | 1 | \(d^{\mathrm{on}}\) 连续增加 |

为简化当前帧递推，记 \(c_{n,i}=c_{n,10,i}\)、\(v_{n,i}=v_{n,10,i}\)。持续时间更新为：

\[
d^{\mathrm{on}}_{n,i}
=
\begin{cases}
\min(d^{\mathrm{on}}_{n-1,i}+1,d_{\mathrm{cap}}),
& c_{n,i}v_{n,i}=1,\\
0,
& \text{otherwise},
\end{cases}
\]

\[
d^{\mathrm{off}}_{n,i}
=
\begin{cases}
\min(d^{\mathrm{off}}_{n-1,i}+1,d_{\mathrm{cap}}),
& c_{n,i}=1,\ v_{n,i}=0,\\
0,
& \text{otherwise}.
\end{cases}
\]

持续时间从当前在线会话起点累计。这样，冷启动和重连都具有明确的时间语义。

窗口槽位中的持续时间继承对应真实帧的状态：

\[
d^{\mathrm{state}}_{n,s,i}
=
d^{\mathrm{state}}_{n+t_s,i},
\qquad
\mathrm{state}\in\{\mathrm{off},\mathrm{on}\}.
\]

### 2.7 连续可靠度与区域覆盖

#### 2.7.1 单 Tracker 可靠度

位置和旋转分别计算 soft 可靠度权重：

\[
w^{\mathrm{type}}_{n,s,i}
=
c_{n,s,i}v_{n,s,i}
\min\!\left(
1,
\frac{d^{\mathrm{on}}_{n,s,i}}{d^{\mathrm{type}}_{\mathrm{warm}}}
\right),
\qquad
\mathrm{type}\in\{\mathrm{pos},\mathrm{rot}\}.
\]

\(w^{\mathrm{type}}\in[0,1]\) 表示测量从“不可用”到“稳定可信”的连续过渡：

- 未配置或掉线时，\(w^{\mathrm{type}}=0\)；
- 刚重连时，\(w^{\mathrm{type}}\) 从小值逐渐增加；
- 连续有效达到 warm-up 后，\(w^{\mathrm{type}}=1\)。

这种设计避免重连测量在单帧内从完全无效跳变为完全可信。

#### 2.7.2 区域覆盖度

24 个关节划分为五个目标区域：

| 区域 | 关节 |
|---|---|
| torso | Pelvis、Spine1、Spine2、Spine3、Neck、Head、左右 Collar |
| left arm | Left Shoulder、Left Elbow、Left Wrist、Left Hand |
| right arm | Right Shoulder、Right Elbow、Right Wrist、Right Hand |
| left leg | Left Hip、Left Knee、Left Ankle、Left Foot |
| right leg | Right Hip、Right Knee、Right Ankle、Right Foot |

记 \(r(j)\) 为关节 \(j\) 所属的目标区域。

Tracker 对区域的固定覆盖关系为：

| 区域 | Position Tracker | Rotation Tracker |
|---|---|---|
| torso | Hip | Head、Hip |
| left arm | Left Wrist | Left Wrist |
| right arm | Right Wrist | Right Wrist |
| left leg | Left Foot | Left Foot |
| right leg | Right Foot | Right Foot |

设 \(A^{\mathrm{type}}_{r,i}\in\{0,1\}\) 表示 Tracker \(i\) 是否覆盖区域 \(r\) 的观测类型 \(\mathrm{type}\)，则单节点区域覆盖度为：

\[
a^{\mathrm{type}}_{n,s,r}
=
1-
\prod_i
\left(
1-A^{\mathrm{type}}_{r,i}w^{\mathrm{type}}_{n,s,i}
\right).
\]

| 变量 | 含义 |
|---|---|
| \(\mathrm{type}\) | 观测类型，取 \(\mathrm{pos}\) 或 \(\mathrm{rot}\) |
| \(w^{\mathrm{type}}_{n,s,i}\) | Tracker \(i\) 在槽位 \(s\) 对该观测类型的连续可靠度 |
| \(d^{\mathrm{type}}_{\mathrm{warm}}\) | 该观测类型从重连恢复到完全可信所需的连续有效帧数 |
| \(A^{\mathrm{type}}_{r,i}\) | Tracker \(i\) 是否能够为区域 \(r\) 提供该类观测 |
| \(a^{\mathrm{type}}_{n,s,r}\) | 区域 \(r\) 在该槽位获得的综合观测覆盖度 |

\(a^{\mathrm{type}}=0\) 表示区域没有直接证据，\(a^{\mathrm{type}}=1\) 表示至少存在完全可靠的覆盖。Noisy-OR 允许多个 Tracker 对同一区域共同提供证据。

### 2.8 Soft-Hard 约束状态

Soft 权重控制测量如何进入网络；hard gate 决定当前旋转是否可以被严格替换：

\[
m^{\mathrm{hard}}_{n,i}
=
c_{n,10,i}v_{n,10,i}
\mathbb 1
[d^{\mathrm{on}}_{n,10,i}\ge d_{\mathrm{hard}}].
\]

这里，\(m^{\mathrm{hard}}_{n,i}\) 表示 Tracker \(i\) 的当前旋转能否进入硬替换集合，\(d_{\mathrm{hard}}\) 是进入该集合所需的连续稳定帧数。Soft 可靠度 \(w\) 决定“读多少”，hard state 决定“是否严格替换”。

Head 是当前参考系和世界解析锚点，因此始终满足：

\[
m^{\mathrm{hard}}_{n,\mathrm{Head}}=1.
\]

其余 Tracker 只有在连续稳定后进入 hard 集合。由此形成明确分工：

| 测量状态 | 网络条件 | Hard projection |
|---|---|---|
| 无效 | 不读取 position / rotation | 不启用 |
| 恢复期 | 按 \(w^{\mathrm{type}}\) 逐渐增强 | 不启用 |
| 稳定期 | 完全读取 | 当前旋转严格替换 |

### 2.9 观测 token 与历史可信度

#### 2.9.1 逐帧观测编码

对每个窗口槽位，Window Observation Encoder 分别产生三类 token 序列：

\[
E^{\mathrm{state}}
\in
\mathbb R^{N_{\mathrm{batch}}\times11\times6\times d_{\mathrm{model}}},
\]

\[
E^{\mathrm{pos}}
\in
\mathbb R^{N_{\mathrm{batch}}\times11\times5\times d_{\mathrm{model}}},
\]

\[
E^{\mathrm{rot}}
\in
\mathbb R^{N_{\mathrm{batch}}\times11\times6\times d_{\mathrm{model}}}.
\]

其中，\(E^{\mathrm{state}}\)、\(E^{\mathrm{pos}}\) 和 \(E^{\mathrm{rot}}\) 分别是状态、位置和旋转 token 序列；\(N_{\mathrm{batch}}\) 是 batch size，\(d_{\mathrm{model}}\) 是每个 token 的隐空间维度。Position 不使用 Head 位置，因此只有 5 个 Tracker token；Rotation 使用全部 6 个 Tracker token。

三类 token 分别回答：

| Token | 回答的问题 |
|---|---|
| State | Tracker 是否配置、是否有效、已掉线或恢复多久 |
| Position | 当前有哪些区域位置证据 |
| Rotation | 当前有哪些区域朝向证据 |

每个 Tracker token 加入身份 embedding。State token 对全部关节可见；Position 和 Rotation token 通过区域覆盖关系与可靠度路由。

观测编码保持完整时间轴，不把历史压缩为单个向量。不同锚点的观测变化随后通过 Temporal Attention 进入当前姿态。

#### 2.9.2 历史区域可信度

历史槽位 \(s=0,\ldots,9\) 的区域可信度定义为：

\[
g^{\mathrm{hist}}_{n,s,r}
=
\frac{
a^{\mathrm{pos}}_{n,s,r}
+
a^{\mathrm{rot}}_{n,s,r}
}{2}.
\]

完整历史可信度序列记为：

\[
G_n
=
\left(g^{\mathrm{hist}}_{n,s,r}\right)_{s=0,\ldots,9;\ r=1,\ldots,5}.
\]

该值同时用于：

1. 缩放历史 Pose token；
2. 调整历史姿态扰动强度；
3. 降低低观测区域的错误历史对当前预测的影响。

因此，历史姿态不是无条件可信的“真值先验”，而是带有区域可信度的闭环状态。

### 2.10 Motion Representation 输出与接口张量

下表统一给出单个在线样本的形状。训练或并行推理时，只需在最前面增加 batch 轴 \(N_{\mathrm{batch}}\)；\(d_{\mathrm{model}}\) 表示 DiT latent dimension。

| 张量 | 形状 | 算法语义 |
|---|---:|---|
| \(X_n\) | \([11,144]\) | Dataset 保留的干净监督窗口；只有 \([X_n]_{s=10}\) 是扩散目标 |
| \(x_{n,k}\) | \([144]\) | 扩散步 \(k\) 的当前帧带噪姿态 |
| \(H_n\) | \([10,144]\) | 过去 deployed 姿态条件序列 |
| \(O_n\) | \([11,6,13]\) | 同步动态 Tracker 观测序列 |
| \(P_n\) | \([11,5]\) | 当前参考系中的 Head 路径 |
| \(G_n\) | \([10,5]\) | 五个身体区域的历史可信度序列 |
| \(M_n\) | \([11]\) | 冷启动有效性序列 |
| \(R_n^{\mathrm{meas}}\) | \([6,3,3]\) | 当前六个 Tracker 的实测旋转集合 |

其中，\(H_n,O_n,P_n,G_n,M_n,T\) 共同构成条件集合 \(\mathcal C_n\)；\(X_n\) 是 Dataset 的干净监督窗口，\(x_n=[X_n]_{s=10}\) 才是训练目标，\(x_{n,k}\) 是进入 Motion Framework 的唯一扩散状态。历史 \(H_n\) 不进入 diffusion Markov chain。\(R_n^{\mathrm{meas}}\) 与 \(M_n^{\mathrm{hard}}\) 是投影阶段使用的当前旋转约束。

## 3. Motion Framework（运动重建框架）

Motion Framework 接收上一部分定义的运动表示，并按照“可靠性感知条件编码—因子化时空生成—逐步旋转投影—世界几何解析”的顺序恢复当前姿态。其主计算链可概括为：

\[
(x_{n,k},k,\mathcal C_n)
\xrightarrow{\ f_\theta\ }
\hat x^{\mathrm{net}}_{n\mid k}
\xrightarrow{\ \mathcal P_R\ }
\hat x^{\mathrm{proj}}_{n\mid k}
\xrightarrow{\ \mathrm{DDIM}\ }
x_{n,k-1},
\qquad k>0,
\]

并在最终步执行：

\[
\tilde x_n
\xrightarrow{\ \mathrm{Resolver}\ }
\left(
p_n^{\mathrm{root},W},
\psi_n^{\mathrm{root},W},
Y_n^W,
R_n^W
\right).
\]

| 变量 | 含义 |
|---|---|
| \(x_{n,k}\) | 第 \(k\) 个扩散步的当前 144D 带噪姿态 |
| \(k\) | 扩散时间步；数值越大，噪声通常越强 |
| \(\mathcal C_n\) | Motion Representation 给出的完整条件集合 |
| \(f_\theta\) | 参数为 \(\theta\) 的因子化时空 DiT |
| \(\hat x^{\mathrm{net}}_{n\mid k}\) | 网络直接预测的当前 clean pose |
| \(\mathcal P_R\) | 合法旋转与稳定 Tracker 旋转的投影算子 |
| \(\hat x^{\mathrm{proj}}_{n\mid k}\) | 投影后的当前 clean pose |
| \(\tilde x_n\) | 最终 deployed 当前帧姿态 |
| \(p_n^{\mathrm{root},W},\psi_n^{\mathrm{root},W}\) | 世界空间 Actor Root 的位置与 yaw |
| \(Y_n^W,R_n^W\) | 世界空间的整组关节位置与旋转 |

### 3.1 因子化时空 DiT

DiT 在 \(11\times24\) 的时间—关节 token 网格上联合建模。下文中，\(b\) 表示 batch 样本，\(s\) 表示时间槽位，\(j\) 表示关节，\(l\) 表示 DiT block，\(d_{\mathrm{model}}\) 表示 token 隐空间维度。

| 变量 | 含义 |
|---|---|
| \(E^{\mathrm{pose}},E^{\mathrm{state}},E^{\mathrm{pos}},E^{\mathrm{rot}}\) | 历史姿态、Tracker 状态、位置和旋转的条件 token 序列 |
| \(e_{b,s,j}\) | 某个 batch、时间槽位和关节位置上的单个 token |
| \(Z^{(l)}\) | 第 \(l\) 个 DiT block 输入的完整时间—关节 token 网格 |
| \(z^{(l)}_{b,s,j}\) | \(Z^{(l)}\) 中的单个 token |
| \(W_x,W_z\) | 分别将当前带噪 rotation6D 与固定历史 rotation6D 映射到 token 空间的可学习矩阵 |
| \(e_k\) | 扩散步 \(k\) 的时间 embedding |
| \(Q^{(l)}\) | 第 \(l\) 个 block 用于读取 Tracker 条件的 query token |
| \(U^{\mathrm{state}},U^{\mathrm{pos}},U^{\mathrm{rot}}\) | 三个 Tracker cross-attention 分支的输出 |
| \(B^{\mathrm{pos}},B^{\mathrm{rot}}\) | 由覆盖关系与连续可靠度产生的 attention bias |
| \(g_{\mathrm{space}},g_{\mathrm{time}},g_{\mathrm{mlp}}\) | AdaLN-Zero 为三个残差分支产生的门控系数 |

#### 3.1.1 历史姿态条件

将 batch 中的历史姿态恢复为 \([N_{\mathrm{batch}},10,24,6]\)。单个历史关节状态 \(h_{b,s,j}\in\mathbb R^6\) 独立映射到 latent：

\[
e^{\mathrm{pose}}_{b,s,j}
=
W_z
h_{b,s,j}
\cdot
g^{\mathrm{hist}}_{b,s,r(j)}.
\]

完整历史 Pose token 序列记为 \(E^{\mathrm{pose}}=(e^{\mathrm{pose}}_{b,s,j})_{b,s,j}\)。令 \(\bar e^{\mathrm{pose}}_{b,s,j}\) 表示补零后序列 \(\bar E^{\mathrm{pose}}\) 中的单个 token。

当前节点没有历史姿态条件，因此在时间轴末尾追加零 token：

\[
\bar E^{\mathrm{pose}}
=
\operatorname{Concat}_s
(E^{\mathrm{pose}},0_{\mathrm{current}})
\in
\mathbb R^{N_{\mathrm{batch}}\times11\times24\times d_{\mathrm{model}}}.
\]

这一设计保证当前真值不会通过历史分支泄漏给模型。

#### 3.1.2 Head path 与时间位置条件

每个 5D Head path 节点 \(p^{\mathrm{head}}_{b,s}\) 经 MLP 编码为 \(e^{\mathrm{head}}_{b,s}\)。不同身体区域使用固定权重 \(w^{\mathrm{head}}_r\)：

| torso | left arm | right arm | left leg | right leg |
|---:|---:|---:|---:|---:|
| 1.0 | 0.25 | 0.25 | 1.0 | 1.0 |

因此：

\[
\bar e^{\mathrm{head}}_{b,s,j}
=
w^{\mathrm{head}}_{r(j)}e^{\mathrm{head}}_{b,s}.
\]

真实帧偏移 \(t_s\) 编码为 \(e^{\mathrm{time}}_{b,s}\)。单个时空位置的静态条件 token 为：

\[
e^{\mathrm{cond}}_{b,s,j}
=
\bar e^{\mathrm{pose}}_{b,s,j}
+
\bar e^{\mathrm{head}}_{b,s,j}
+
e^{\mathrm{time}}_{b,s}.
\]

Head path 对 torso 和双腿影响更强，使转向、行进和高度变化主要控制身体主体与支撑链；手臂保留更大的独立运动自由度。

#### 3.1.3 初始 token

历史与当前使用两条互不重复的输入投影。对历史槽位 \(s<10\)：

\[
z^{(0)}_{b,s,j}
=
W_z h_{b,s,j}\,g^{\mathrm{hist}}_{b,s,r(j)}
+e^{\mathrm{joint}}_j
+e^{\mathrm{region}}_{r(j)}
+\bar e^{\mathrm{head}}_{b,s,j}
+e^{\mathrm{time}}_{b,s}.
\]

对当前槽位 \(s=10\)：

\[
z^{(0)}_{b,10,j}
=
W_x x_{b,k,j}
+e^{\mathrm{joint}}_j
+e^{\mathrm{region}}_{r(j)}
+\bar e^{\mathrm{head}}_{b,10,j}
+e^{\mathrm{time}}_{b,10}.
\]

历史姿态只经过 \(W_z\)，不会再经过 \(W_x\)，从而避免相同历史姿态被重复编码。拼接后仍得到 \([N_{\mathrm{batch}},11,24,d_{\mathrm{model}}]\) token 网格。扩散时间 \(k\) 通过每个 block 的共享 AdaLN-Zero 调制全部 11 个槽位；历史虽然不是 diffusion state，第一版仍使用同一套 timestep modulation。

#### 3.1.4 Block 结构

每个 SpatioTemporal DiT block 依次执行：

~~~text
同帧 Tracker cross-attention
    -> 同帧 24 关节 Spatial Self-Attention
    -> 同关节 11 节点 Prefix-masked Temporal Self-Attention
    -> Token-wise MLP
~~~

这种因子化结构把 \(11\times24\) 时空网格分解为两个明确子问题：

- Spatial Attention 学习同一帧的全身骨架协调；
- Temporal Attention 学习同一关节跨不同时间尺度的运动连续性。

#### 3.1.5 可靠性感知 Tracker cross-attention

第 \(l\) 个 block 的共同 query 网格为：

\[
Q^{(l)}
=
\operatorname{LN}_{\mathrm{cond}}
\left(
Z^{(l)}
\right).
\]

三个观测分支为：

\[
U^{\mathrm{state}}
=
\operatorname{Attn}
(Q^{(l)},E^{\mathrm{state}},E^{\mathrm{state}}),
\]

\[
U^{\mathrm{pos}}
=
\operatorname{Attn}
(Q^{(l)},E^{\mathrm{pos}},E^{\mathrm{pos}};B^{\mathrm{pos}}),
\]

\[
U^{\mathrm{rot}}
=
\operatorname{Attn}
(Q^{(l)},E^{\mathrm{rot}},E^{\mathrm{rot}};B^{\mathrm{rot}}).
\]

Position 和 Rotation 的 attention bias 为：

\[
B^{\mathrm{type}}_{b,s,j,i}
=
\begin{cases}
\log\max(w^{\mathrm{type}}_{b,s,i},10^{-6}),
&
A^{\mathrm{type}}_{r(j),i}=1,\quad
w^{\mathrm{type}}_{b,s,i}>0,\\
-\infty,
&
\text{otherwise}.
\end{cases}
\]

其中 Position 分支只使用五个非 Head Tracker，Rotation 分支使用全部六个 Tracker。

令 \(u^{\mathrm{state}}_{b,s,j}\) 表示 \(U^{\mathrm{state}}\) 中的单个输出 token，\(u^{\mathrm{type}}_{b,s,j}\) 表示 \(U^{\mathrm{type}}\) 中的单个输出 token。当目标区域完全没有对应的 position 或 rotation 观测时，该分支的**有效写回量**定义为零：

\[
a^{\mathrm{type}}_{b,s,r(j)}=0
\quad\Longrightarrow\quad
a^{\mathrm{type}}_{b,s,r(j)}
u^{\mathrm{type}}_{b,s,j}=0.
\]

实现中，全屏蔽 attention 行会临时开放一个数值回退 key，以避免“全部 key 都为 \(-\infty\)”导致未定义 Softmax；由于外层覆盖度 \(a^{\mathrm{type}}=0\)，该分支最终写回仍严格为零。这里区分了“attention 内部的数值回退”与“算法上有效观测贡献为零”。

条件写回为：

\[
\bar z^{(l)}_{b,s,j}
=
z^{(l)}_{b,s,j}
+
u^{\mathrm{state}}_{b,s,j}
+
a^{\mathrm{pos}}_{b,s,r(j)}
u^{\mathrm{pos}}_{b,s,j}
+
a^{\mathrm{rot}}_{b,s,r(j)}
u^{\mathrm{rot}}_{b,s,j}.
\]

这里存在两级可靠度控制：

1. \(\log w\) 在 key 侧影响多个 Tracker 之间的 attention 权重；
2. \(a\) 在输出侧控制该观测类型对整个目标区域的写入强度。

#### 3.1.6 Spatial Self-Attention

空间分支先把 cross-attention 后的 token 重排为：

\[
Z^{\mathrm{space,in}}
\in
\mathbb R^{(N_{\mathrm{batch}}\cdot11)\times24\times d_{\mathrm{model}}}.
\]

扩散时间 embedding \(e_k\) 产生 AdaLN shift、scale 与 residual gate：

\[
Q^{\mathrm{space}}
=
\operatorname{AdaLN}
\left(
\operatorname{LN}_{\mathrm{space}}
(Z^{\mathrm{space,in}});
e_k
\right),
\]

\[
Z^{\mathrm{space,out}}
=
Z^{\mathrm{space,in}}
+
g_{\mathrm{space}}(e_k)
\operatorname{SelfAttn}
(Q^{\mathrm{space}}).
\]

该分支允许手腕证据沿手臂链传播，允许 Hip 和 Foot 证据共同约束支撑姿态，并保持躯干与四肢的全身协调。

#### 3.1.7 固定历史前缀 Temporal Self-Attention

时间分支把 \(Z^{\mathrm{space,out}}\) 重排为：

\[
Z^{\mathrm{time,in}}
\in
\mathbb R^{(N_{\mathrm{batch}}\cdot24)\times11\times d_{\mathrm{model}}}.
\]

每个历史 token 与当前 token 都经过标准可学习投影得到完整 Q/K/V。角色可见性矩阵固定为：

\[
M^{\mathrm{role}}
=
\begin{bmatrix}
\mathbf 1_{10\times10} & \mathbf 0_{10\times1}\\
\mathbf 1_{1\times10} & 1
\end{bmatrix}.
\]

结合冷启动有效性后：

\[
M^{\mathrm{allow}}_{b,s,s'}
=
M^{\mathrm{role}}_{s,s'}\,m_{b,s}\,m_{b,s'}.
\]

因此，有效历史 query 可以双向读取全部有效历史 key，但不能读取当前 key；当前 query 可以读取全部有效历史和自己；padding 永远不能作为 key。若 padding query 被全屏蔽，实现只临时开放其自身以保持 Softmax 有限，block 输出后再将该行清零。

\[
Q^{\mathrm{time}}
=
\operatorname{AdaLN}
\left(
\operatorname{LN}_{\mathrm{time}}
(Z^{\mathrm{time,in}});
e_k
\right),
\]

\[
Z^{\mathrm{time,out}}
=
Z^{\mathrm{time,in}}
+
\gamma_{b,s,j}\,g_{\mathrm{time}}(e_k)
\operatorname{SelfAttn}
(Q^{\mathrm{time}};M^{\mathrm{allow}}).
\]

可靠度 residual gate 为：

\[
\gamma_{b,s,j}
=
\begin{cases}
1, & s<10\ \text{且}\ m_{b,s}=1,\\
\max\!\left(1-\tfrac12(\rho^{\mathrm{pos}}_{b,10,r(j)}+\rho^{\mathrm{rot}}_{b,10,r(j)}),0.1\right), & s=10,\\
0, & m_{b,s}=0.
\end{cases}
\]

历史行由此完整互相建模，只有当前行根据当前区域 Tracker coverage 调整 temporal residual；AdaLN 学习得到的 temporal gate 仍然保留。

由于每个历史节点已经经过同帧空间注意力，当前关节读取到的不只是该关节的原始历史，而是带有历史全身上下文的同关节表示。

#### 3.1.8 MLP 与输出

Block 最后执行：

\[
Z^{(l+1)}
=
Z^{\mathrm{time,out}}
+
g_{\mathrm{mlp}}(e_k)
\operatorname{MLP}
\left(
\operatorname{AdaLN}
(
\operatorname{LN}_{\mathrm{mlp}}
(Z^{\mathrm{time,out}});
e_k
)
\right).
\]

最终只解码当前槽位：

\[
\hat x^{\mathrm{net}}_{n\mid k}
\in
\mathbb R^{N_{\mathrm{batch}}\times144}.
\]

历史 token 不创建输出或 reconstruction loss，但当前 loss 可通过 Temporal Attention 反向传播到 \(W_z\) 和历史条件编码路径。

当前时间节点还产生两个辅助输出：

| 输出 | 形状 | 语义 |
|---|---:|---|
| Future-leg | \([N_{\mathrm{batch}},3,8,6]\) | 未来 3 帧、8 个腿部关节的 rotation6D |
| Contact | \([N_{\mathrm{batch}},2]\) | 当前左右脚接触 logits |

辅助头提供短期腿部趋势和支撑状态监督，但不直接修改扩散状态。

### 3.2 Projected DDIM

Projected DDIM 在每个反向扩散步中先获得当前帧 clean-pose estimate，再将其投影到可部署旋转空间，并用投影结果重新计算该步噪声。历史条件在所有反向步中保持固定。

| 变量 | 含义 |
|---|---|
| \(K\) | 总扩散步数，当前默认值为 50 |
| \(k\) | 当前扩散步，反向采样时从 \(K-1\) 递减到 0 |
| \(\beta_k,\alpha_k\) | 单步噪声系数及其保留系数，\(\alpha_k=1-\beta_k\) |
| \(\bar\alpha_k\) | 从第 0 步累计到第 \(k\) 步的信号保留系数 |
| \(\epsilon_n\) | 前向扩散时只作用于当前 144D 姿态的标准高斯噪声 |
| \(\hat\epsilon_{n,k}\) | 根据当前带噪姿态和 clean estimate 反解得到的噪声 |
| \(R_n^{\mathrm{meas}}\) | 当前六个 Tracker 在 \(F_n\) 中的实测旋转集合 |
| \(M_n^{\mathrm{hard}}\) | 当前六个 Tracker 是否启用旋转硬替换的状态序列 |
| \(\hat x^{\mathrm{step}}_{n\mid k}\) | 第 \(k\) 步真正用于 DDIM 更新的当前 clean-pose estimate |
| \(\eta\) | DDIM 随机性系数，当前默认值为 0 |
| \(\sigma_k\) | 第 \(k\) 步实际注入的随机噪声强度 |
| \(\epsilon'_{n,k}\) | DDIM 更新中的新标准高斯噪声 |
| \(\tilde x_n\) | 最终 deployed 当前姿态 |

#### 3.2.1 仅当前帧扩散

令扩散索引 \(k\in\{0,\ldots,K-1\}\)，\(\alpha_k=1-\beta_k\)，并定义累计噪声系数：

\[
\bar\alpha_k
=
\prod_{q=0}^{k}\alpha_q.
\]

只对当前姿态执行前向扩散：

\[
x_{n,k}
=
\sqrt{\bar\alpha_k}x_n
+
\sqrt{1-\bar\alpha_k}\,
\epsilon_n,
\qquad
\epsilon_n\sim\mathcal N(0,I),
\qquad
\epsilon_n\in\mathbb R^{144}.
\]

历史 \(H_n\) 不加噪、不更新，也不需要扩散后的 padding 清零。网络临时把固定历史 token 与当前带噪 token 拼成 11 帧时空网格。

模型采用当前 clean-pose prediction：

\[
\hat x^{\mathrm{net}}_{n\mid k}
=
f_\theta
(x_{n,k},k,\mathcal C_n)_{\mathrm{current}}.
\]

\(\hat x^{\mathrm{net}}_{n\mid k}\) 只表示当前 clean pose 的预测。历史不是 inpainting 区域，因为它从未进入扩散状态；它是独立、固定且可由当前 loss 反向训练的条件路径。

#### 3.2.2 SO(3) 与 hard rotation projection

令当前六个 Tracker 的实测旋转集合与 hard enforcement 序列分别为：

\[
R_n^{\mathrm{meas}}
=
\left(R^{F_n}_{n,10,i}\right)_{i=1}^{6},
\qquad
M_n^{\mathrm{hard}}
=
\left(m^{\mathrm{hard}}_{n,i}\right)_{i=1}^{6}.
\]

定义投影算子：

\[
\hat x^{\mathrm{proj}}_{n\mid k}
=
\mathcal P_R
\left(
\hat x^{\mathrm{net}}_{n\mid k};
R_n^{\mathrm{meas}},
M_n^{\mathrm{hard}}
\right).
\]

投影依次执行：

1. 将标准化网络预测恢复到物理 rotation6D 空间；
2. 对当前帧 24 个关节执行稳定 Gram-Schmidt；
3. 对当前 hard Tracker 对应关节执行全局旋转替换；
4. 重新编码为 rotation6D 并回到扩散空间。

Tracker 与关节的固定对应关系为：

| Tracker | Head | Left Wrist | Right Wrist | Hip | Left Foot | Right Foot |
|---|---|---|---|---|---|---|
| Joint | Head | Left Wrist | Right Wrist | Pelvis | Left Foot | Right Foot |

只有旋转进入 hard projection。位置测量仍以 soft 条件和几何损失参与，因为严格满足位置需要额外 IK 或约束优化。

#### 3.2.3 用 projected current clean pose 推进采样

当前 step 真正采用的 clean-pose estimate 为：

\[
\hat x^{\mathrm{step}}_{n\mid k}
=
\begin{cases}
\hat x^{\mathrm{proj}}_{n\mid k},
& \text{该 step 启用投影},\\
\hat x^{\mathrm{net}}_{n\mid k},
& \text{该 step 不启用投影}.
\end{cases}
\]

由 \(\hat x^{\mathrm{step}}_{n\mid k}\) 重新计算当前帧噪声：

\[
\hat\epsilon_{n,k}
=
\frac{
x_{n,k}
-
\sqrt{\bar\alpha_k}
\hat x^{\mathrm{step}}_{n\mid k}
}{
\sqrt{1-\bar\alpha_k}
}.
\]

DDIM 更新为：

\[
\sigma_k
=
\eta
\sqrt{
\frac{
1-\bar\alpha_{k-1}
}{
1-\bar\alpha_k
}
}
\sqrt{
1-
\frac{
\bar\alpha_k
}{
\bar\alpha_{k-1}
}
},
\]

\[
x_{n,k-1}
=
\sqrt{\bar\alpha_{k-1}}
\hat x^{\mathrm{step}}_{n\mid k}
+
\sqrt{
1-\bar\alpha_{k-1}-\sigma_k^2
}
\hat\epsilon_{n,k}
+
\sigma_k \epsilon'_{n,k},
\qquad k>0,
\]

其中 \(\epsilon'_{n,k}\sim\mathcal N(0,I)\) 与当前姿态同形。默认 \(\eta=0\)，因此采样轨迹在给定初始 \(x_{n,K-1}\) 后是确定的。最终扩散步 \(k=0\) 直接输出：

\[
\tilde x_n
=
\hat x^{\mathrm{proj}}_{n\mid0}.
\]

Projected DDIM 的关键不是最终覆盖一次 Tracker 旋转，而是让投影后的 clean-pose estimate 改变后续全部去噪轨迹。

#### 3.2.4 Algorithm 1：Projected DDIM

~~~text
输入：
    已编码的窗口条件
    当前 Tracker 原始旋转
    当前 hard rotation state
    投影模式
    DDIM 时间步数 K

x_{n,K-1} <- [144] 高斯噪声

for k = K-1, ..., 0:
    net_clean <- SpatioTemporalDiT(x_{n,k}, k, conditions_n)[current]
    proj_clean <- P_R(net_clean)

    if 当前模式在第 k 步启用投影:
        step_clean <- proj_clean
    else:
        step_clean <- net_clean

    noise_k <- 由 x_{n,k} 和 step_clean 重新计算

    if k > 0:
        x_{n,k-1} <- DDIM(step_clean, noise_k, k)
    else:
        final_net_pose <- net_clean
        deployed_pose <- proj_clean

返回 final_net_pose、deployed_pose 与辅助输出
~~~

#### 3.2.5 Soft-Hard 原则

方法遵循：

> 只有能够稳定、低成本并以闭式形式满足的约束进入 Hard；其余证据通过可靠性感知的 Soft conditioning 参与生成。

对应关系为：

| 信息 | 处理方式 |
|---|---|
| Tracker 状态 | State conditioning |
| 恢复期 position / rotation | 由 \(w^{\mathrm{pos}}\)、\(w^{\mathrm{rot}}\) 控制的 soft conditioning |
| 历史姿态与 Head path | 时空条件 |
| 合法旋转 | 当前帧 SO(3) projection |
| 稳定 Tracker rotation | 由 \(M_n^{\mathrm{hard}}\) 控制的当前帧 hard replacement |
| Tracker position | Soft condition 与几何损失 |
| Root 平移 | Head-anchored deterministic resolver |

### 3.3 训练目标

训练目标只监督当前帧网络结果与加入确定性约束后的当前 deployed 结果。历史 token 不产生输出或 reconstruction loss。

| 变量 | 含义 |
|---|---|
| \(L_b^{\mathrm{simple}}\) | 样本 \(b\) 当前 144D 姿态的 diffusion reconstruction loss |
| \(\mathcal L_q\) | 第 \(q\) 类旋转、几何或辅助损失 |
| \(\lambda_q\) | 第 \(q\) 类损失的内部权重 |
| \(\lambda_{\mathrm{diff}},\lambda_{\mathrm{aux}}\) | 扩散重建与辅助损失两大部分的权重 |

#### 3.3.1 当前帧 diffusion reconstruction

令 \(\hat x^{\mathrm{net}}_{b\mid k}\in\mathbb R^{144}\) 为网络当前帧输出，\(x_b\) 为当前干净目标。MSE 配置下：

\[
L_b^{\mathrm{simple}}
=
\frac{1}{144}
\sum_{f=1}^{144}
\left(
\hat x^{\mathrm{net}}_{b\mid k,f}-x_{b,f}
\right)^2.
\]

L1 配置只把平方误差替换为绝对误差；feature weighting 仍沿 144D 特征轴执行。现有 temporal rotation loss 已移除，本次不添加替代平滑项。虽然没有历史重建项，当前 loss 仍可经非对称 Temporal Attention 训练历史输入投影与历史条件路径。

#### 3.3.2 Network 与 deployed 监督

Network 输出 \(\hat x^{\mathrm{net}}\) 反映网络自身的生成能力；deployed 输出 \(\tilde x\) 反映加入确定性约束后的实际结果。两条路径均只描述当前帧：

| 损失 | 作用结果 | 目标 |
|---|---|---|
| Global rotation | Network | 24 个当前关节的 SO(3) 角误差 |
| Local rotation | Network | 父子相对旋转误差 |
| Tracker rotation | Network | 所有当前有效 Tracker 的旋转一致性 |
| FK coordinate | Deployed | Head 参考系中的关节坐标 |
| Joint distance | Deployed | 关节欧氏位置误差 |
| Tracker position | Deployed | 非 Head Tracker 的位置一致性 |
| Root yaw | Deployed | 世界 Pelvis heading |
| Head-to-Root XZ | Deployed | Head 与 Actor Root 的水平关系 |
| Future-leg | Auxiliary | 未来腿部旋转 |
| Contact | Auxiliary | 当前双脚接触 |

即使某个关节最终由 hard projection 替换，Network 分支仍受到扩散、旋转和 Tracker rotation 监督，避免网络退化为依赖投影的无效预测器。

Tracker position 使用三维径向 Huber。令 \(d\) 为预测位置与测量位置的欧氏距离，\(d_0>0\) 为转折距离：

\[
\mathcal H_{d_0}(d)
=
\begin{cases}
\frac{d^2}{2d_0},
& d<d_0,\\
d-\frac{d_0}{2},
& d\ge d_0.
\end{cases}
\]

#### 3.3.3 总损失

总损失写为：

\[
\mathcal L
=
\lambda_{\mathrm{diff}}
\mathbb E_b[L_b^{\mathrm{simple}}]
+
\lambda_{\mathrm{aux}}
\sum_{q\in\mathcal Q}
\lambda_q
\mathcal L_q.
\]

其中 \(\mathcal Q\) 是辅助损失类型集合，\(\mathcal L_q\) 汇总旋转、FK、Tracker、Root、Future-leg 和 Contact 监督。该目标同时约束：

- Network 姿态生成质量；
- Deployed 几何一致性；
- 欠观测腿部的短期趋势；
- 支撑与接触状态。

#### 3.3.4 历史姿态扰动

在线历史来自过去预测，而训练历史来自干净数据。为减小二者的分布差异，只对独立历史条件 \(H_n\) 添加 SO(3) 扰动，不改变当前扩散监督 \(x_n=[X_n]_{s=10}\)。

扰动以样本级概率 \(p_{\mathrm{aug}}=0.8\) 启用，只作用于有效历史槽位。

历史扰动在 \(SO(3)\) 切空间中的逐分量标准差由区域可信度决定：

\[
\sigma_{\mathrm{hist}}(g)
=
\sigma_{\min}
+
(1-g)
(\sigma_{\max}-\sigma_{\min}).
\]

当前标准差范围为 \(2^\circ\) 到 \(10^\circ\)，进入指数映射前统一换算为弧度。令 \(u^{\mathrm{region}}\) 和 \(u^{\mathrm{joint}}\) 为零均值、单位方差的三维高斯向量；不同区域或关节的随机过程相互独立。单个关节的切空间扰动为：

\[
u^{\mathrm{noise}}_{b,s,j}
=
\sigma_{\mathrm{hist}}
\left(
g^{\mathrm{hist}}_{b,s,r(j)}
\right)
\left(
\sqrt{\lambda_{\mathrm{region}}}\,
u^{\mathrm{region}}_{b,s,r(j)}
+
\sqrt{\lambda_{\mathrm{joint}}}\,
u^{\mathrm{joint}}_{b,s,j}
\right).
\]

两项权重先归一化为和等于 1；默认 \(\lambda_{\mathrm{region}}=0.75\)、\(\lambda_{\mathrm{joint}}=0.25\)，分别控制区域共享误差与关节独立误差。

扰动通过指数映射右乘到干净历史旋转，而不是直接加到 rotation6D：

\[
R^{\mathrm{hist,aug}}_{b,s,j}
=
R^{\mathrm{hist}}_{b,s,j}
\operatorname{Exp}
\left(
\left[u^{\mathrm{noise}}_{b,s,j}\right]_{\times}
\right).
\]

两类噪声沿时间相关，并按锚点真实间隔使用：

\[
\operatorname{corr}
\left(
u^{\mathrm{region}}_{b,s,r},
u^{\mathrm{region}}_{b,s',r}
\right)
=
\operatorname{corr}
\left(
u^{\mathrm{joint}}_{b,s,j},
u^{\mathrm{joint}}_{b,s',j}
\right)
=
r_{\mathrm{time}}^{|t_{s'}-t_s|},
\qquad 0\le s,s'<10.
\]

| 变量 | 含义 |
|---|---|
| \(p_{\mathrm{aug}}\) | 一个训练样本启用历史扰动的概率 |
| \(g^{\mathrm{hist}}_{b,s,r(j)}\) | 关节 \(j\) 所属区域在历史槽位 \(s\) 的可信度 |
| \(\sigma_{\min},\sigma_{\max}\) | 完全可信与最低可信历史对应的扰动标准差 |
| \(u^{\mathrm{region}}\) | 同一区域关节共享的三维标准高斯过程 |
| \(u^{\mathrm{joint}}\) | 每个关节独立的三维标准高斯过程 |
| \(u^{\mathrm{noise}}_{b,s,j}\) | 最终施加到单个历史关节的切空间扰动向量 |
| \(\lambda_{\mathrm{region}},\lambda_{\mathrm{joint}}\) | 区域共享噪声与关节独立噪声的方差比例 |
| \([u]_{\times}\) | 将三维向量 \(u\) 转换为反对称矩阵 |
| \(\operatorname{Exp}\) | 从 \(\mathfrak{so}(3)\) 切空间映射到 \(SO(3)\) 的指数映射 |
| \(r_{\mathrm{time}}\) | 相隔一帧时的基础时间相关系数 |

区域共享噪声模拟整条肢体或躯干的系统性部署误差，关节噪声模拟局部预测误差。

#### 3.3.5 动态观测与冷启动训练

训练覆盖五类动态条件：

1. 持续六点；
2. 持续三点；
3. 三点切换到六点；
4. 六点切换到三点；
5. 两个非 Head Tracker 同步掉线并重连。

冷启动样本随机缩短可见历史，使模型同时学习：

- 无历史首帧；
- 部分历史；
- 完整一秒历史。

当前训练不展开多步模型 rollout。闭环误差主要通过历史姿态扰动近似，真实误差累积则在在线长序列推理中检验。

### 3.4 Head-Anchored 世界解析

网络只生成当前 Head-yaw 参考系中的关节旋转；Resolver 使用当前 Head 高度、Head 水平位置、预测骨架几何和骨架 rest offset，闭式恢复 Pelvis 高度、Actor Root 和世界关节状态。

| 变量 | 含义 |
|---|---|
| \(\tilde R_n^{F_n}\) | deployed 当前帧在 \(F_n\) 中的 24 个全局关节旋转 |
| \(\hat\psi_n^{\mathrm{root},F_n}\) | 从预测 Pelvis 旋转提取的相对 Head root heading |
| \(o_j^{\mathrm{bone}}\) | 关节 \(j\) 相对父关节的骨架 rest offset |
| \(Y_n^{\mathrm{rel},F_n}\) | 以 Pelvis 为零点的整组相对关节位置 |
| \(\operatorname{parent}(j)\) | 骨架树中关节 \(j\) 的父关节编号 |
| \(h_n^{\mathrm{obs}}\) | 当前 Head Tracker 相对地面的观测高度 |
| \(h_n^{\mathrm{pelvis}}\) | 根据 Head 高度和 FK 几何解析得到的 Pelvis 高度 |
| \(p_n^{\mathrm{root},F_n}\) | 为使预测 Head 与观测 Head 水平对齐而得到的 Root 平移 |
| \(R^W_{F_n}\) | 从当前 Head-yaw 参考系 \(F_n\) 到世界系 \(W\) 的旋转 |
| \(Y_n^W,R_n^W\) | 解析后的世界关节位置序列与旋转序列 |

#### 3.4.1 Pelvis-relative FK

Resolver 只解析 deployed 当前帧。将 \(\tilde x_n\) 转换为 24 个合法全局旋转，得到旋转序列：

\[
\tilde R_n^{F_n}
=
\left(
\tilde R_{n,j}^{F_n}
\right)_{j=1}^{24}.
\]

由 Pelvis 旋转提取相对当前 Head yaw 的 root heading：

\[
\hat\psi_n^{\mathrm{root},F_n}
=
\operatorname{heading}
\left(
\tilde R_{n,\mathrm{Pelvis}}^{F_n}
\right).
\]

以 Pelvis 为相对位置零点，根据骨架 rest offset \(o_j^{\mathrm{bone}}\) 执行 FK。大写 \(Y_n^{\mathrm{rel},F_n}\) 表示整组关节位置，小写 \(y_{n,j}^{\mathrm{rel},F_n}\) 表示单个关节：

\[
Y_n^{\mathrm{rel},F_n}
=
\left(
y_{n,j}^{\mathrm{rel},F_n}
\right)_{j=1}^{24},
\qquad
y_{n,\mathrm{Pelvis}}^{\mathrm{rel},F_n}=0,
\]

\[
y_{n,j}^{\mathrm{rel},F_n}
=
y_{n,\operatorname{parent}(j)}^{\mathrm{rel},F_n}
+
\tilde R_{n,\operatorname{parent}(j)}^{F_n}
o_j^{\mathrm{bone}},
\qquad j\ne \mathrm{Pelvis}.
\]

当前 Head Tracker 相对地面的观测高度为：

\[
h_n^{\mathrm{obs}}
=
p^{F_n}_{n,10,\mathrm{Head},y}
=
p^W_{\mathrm{Head},n,y}-y_{\mathrm{floor}}.
\]

Pelvis 高度由 Head 观测与预测骨架几何闭式解析：

\[
h_n^{\mathrm{pelvis}}
=
h_n^{\mathrm{obs}}
-
y_{n,\mathrm{Head},y}^{\mathrm{rel},F_n}.
\]

#### 3.4.2 Root 水平平移

令 Actor Root 到 Pelvis 的 rest offset 为 \(o_{\mathrm{Pelvis}}^{\mathrm{bone}}\)。先把其纵向分量替换为解析得到的 Pelvis 高度：

\[
\bar o_n^{\mathrm{pelvis}}
=
\begin{bmatrix}
o_{\mathrm{Pelvis},x}^{\mathrm{bone}} & h_n^{\mathrm{pelvis}} & o_{\mathrm{Pelvis},z}^{\mathrm{bone}}
\end{bmatrix}^{\!\top}.
\]

使用预测 root heading 旋转该 offset，得到 Head 水平对齐前的 Pelvis 位置与关节位置：

\[
\bar p_n^{\mathrm{pelvis},F_n}
=
R_y
\left(
\hat\psi_n^{\mathrm{root},F_n}
\right)
\bar o_n^{\mathrm{pelvis}},
\qquad
\bar y_{n,j}^{F_n}
=
y_{n,j}^{\mathrm{rel},F_n}
+
\bar p_n^{\mathrm{pelvis},F_n}.
\]

随后用 Actor Root 在 \(F_n\) 中的位置整体平移骨架，使预测 Head 的 XZ 与当前参考系原点对齐：

\[
p_n^{\mathrm{root},F_n}
=
\begin{bmatrix}
-\bar y_{n,\mathrm{Head},x}^{F_n}\\
0\\
-\bar y_{n,\mathrm{Head},z}^{F_n}
\end{bmatrix},
\qquad
\tilde y_{n,j}^{F_n}
=
\bar y_{n,j}^{F_n}
+
p_n^{\mathrm{root},F_n}.
\]

大写 \(\tilde Y_n^{F_n}=(\tilde y_{n,j}^{F_n})_{j=1}^{24}\) 表示对齐后的整组关节位置。该解析将 Root 水平位置绑定到观测 Head，同时保留姿态网络对身体相对 Head 几何的预测能力；解析后 \(\tilde y_{n,\mathrm{Head},x}^{F_n}=\tilde y_{n,\mathrm{Head},z}^{F_n}=0\)。

#### 3.4.3 恢复世界结果

世界空间 Actor Root 位置为：

\[
p_n^{\mathrm{root},W}
=
p_n^{\mathrm{ref},W}
+
R^W_{F_n}
p_n^{\mathrm{root},F_n},
\qquad
\left[p_n^{\mathrm{root},W}\right]_y=y_{\mathrm{floor}}.
\]

世界关节位置序列 \(Y_n^W=(y_{n,j}^W)_{j=1}^{24}\) 与旋转序列 \(R_n^W=(R_{n,j}^W)_{j=1}^{24}\) 分别为：

\[
y_{n,j}^W
=
p_n^{\mathrm{ref},W}
+
R^W_{F_n}
\tilde y_{n,j}^{F_n},
\]

\[
R_{n,j}^W
=
R^W_{F_n}
\tilde R_{n,j}^{F_n}.
\]

Actor Root 的世界 yaw 为：

\[
\psi_n^{\mathrm{root},W}
=
\psi^W_{\mathrm{Head},n}
+
\hat\psi_n^{\mathrm{root},F_n}.
\]

Resolver 不执行 IK 或迭代优化，只使用一次 FK 和闭式 Head 对齐。它把生成问题限制在关节旋转空间，同时保证 Actor Root、Pelvis 高度和世界关节与当前 Head 观测使用同一个几何锚点。

### 3.5 Algorithm 2：单帧在线推理与闭环

~~~text
输入：
    当前六个 Tracker 世界变换
    configured 与 measured_valid
    当前 floor
    过去最多 60 帧 deployed 世界姿态与 Tracker 状态

1. 更新 d_off、d_on、w、a 和 hard_rotation_mask
2. 从密集历史抽取 10 个固定锚点
3. 将历史 Pose、Tracker 和 Head path 统一转换到当前 F_n
4. 构造 G_n、M_n 与真实帧偏移 T
5. 编码完整条件 conditions_n
6. 以 [144] 当前噪声执行 Projected DDIM，历史条件保持固定
7. 得到当前 deployed pose
8. 通过 Head-anchored resolver 恢复世界 Root 和关节
9. 将当前 deployed 世界状态写入历史

输出：
    当前 144D pose
    Actor Root position / yaw
    Pelvis height
    世界关节位置与旋转
~~~

## 4. 算法性质与边界

### 4.1 因果性与信息边界

| 信息 | 历史节点可读 | 当前节点可读 |
|---|---:|---:|
| 同一槽位的 Tracker 条件 | 是 | 是 |
| 同一槽位的其他 joint token | 是 | 是 |
| 更早时间节点 | 是 | 是 |
| 更晚历史锚点 | 是 | 是 |
| 当前槽位的带噪 pose token | 否 | 是 |
| 未来帧 | 否 | 否 |
| 当前 clean pose 真值条件 | 否 | 否 |

当前姿态真值只作为扩散监督，不进入历史条件。Temporal Attention 使用固定历史前缀 mask：历史内部双向可见，历史不能读取当前，当前可以读取全部有效历史与自己。对所有有效 query，冷启动 padding 都不能作为 key；padding query 的自回退只用于保持数值有限，随后立即清零。这里的历史双向注意力不会泄漏未来信息，因为 10 个历史锚点在在线帧 \(n\) 都已经发生。

### 4.3 抖动评估边界

是否改善抖动不能由结构直接断言。长序列评估除 MPJRE、MPJPE、MPJVE、MPJAE、foot slide 和 Tracker 一致性外，还计算预测关节 Jitter：

\[
j_n
=
\frac{1}{|\mathcal J_{\mathrm{paper}}|}
\sum_{j\in\mathcal J_{\mathrm{paper}}}
\left\|
\Delta^3 p_{n,j}^{\mathrm{pred}}
\right\|_2
\,fps^3.
\]

单位为 \(\mathrm{m/s^3}\)，每条序列前三帧记为 NaN。该指标进入全局、scenario、掉线持续时间、重连阶段和 cold-start/steady-state 分组。长序列噪声支持 `per_frame`、`fixed_sequence` 与 `correlated`；三者都只生成当前 \([144]\) diffusion noise。相关噪声使用：

\[
\epsilon_n
=
\rho\epsilon_{n-1}
+
\sqrt{1-\rho^2}\eta_n.
\]

必须结合速度、加速度和 foot slide 判断 Jitter 下降是否来自过度平滑。

### 4.4 方法优势

- **动态观测语义明确。** 未配置、掉线、重连和稳定状态不再共享同一种输入表示。
- **时间与空间结构分离。** 因子化注意力以较低成本建模完整时空窗口。
- **历史可信度可解释。** 历史姿态影响由对应区域的观测覆盖度决定。
- **只扩散部署目标。** 历史作为固定前缀提供上下文，10 帧无部署用途的随机 diffusion latent 被删除。
- **约束参与采样轨迹。** Projected DDIM 不只修正最终输出，而是逐步影响当前帧后续去噪。
- **生成与几何解析解耦。** 网络专注于旋转生成，世界 Root 由可解释几何恢复。
- **闭环部署一致。** 下一帧历史只使用 deployed 结果。

### 4.5 当前边界

- Head 必须始终有效，且 floor 与目标骨架参数已知。
- Position 只作为 soft 证据，不能保证所有 Tracker 位置严格满足。
- 10 个固定锚点压缩了过去一秒历史，可能丢失高频中间运动。
- 训练使用历史扰动近似闭环误差，但不直接优化多步 rollout。
- 扩散采样步数仍是精度与实时延迟之间的主要权衡。
- Hard rotation replacement 保证局部观测一致性，但不等价于完整人体动力学约束。

总体上，该方法把实时稀疏姿态重建表述为一个可靠性感知的因果时空扩散问题：动态 Tracker 提供当前证据，历史 deployed 姿态提供运动上下文，因子化时空 DiT 负责生成全身协调姿态，Projected DDIM 保证旋转可部署性，Head-anchored resolver 则完成从局部旋转到世界人体状态的确定性恢复。
