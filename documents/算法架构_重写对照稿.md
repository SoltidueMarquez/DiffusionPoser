# 实时稀疏追踪姿态重建算法（重写对照稿）

本文说明当前实时稀疏追踪姿态重建算法。系统以 60 Hz 作为输入与目标更新频率，在 Tracker 配置变化、测量掉线和重连的情况下，根据过去 60 帧运动、当前稀疏观测和 Head 运动控制，重建当前帧完整人体姿态。60 Hz 是算法面向的在线数据频率；实际吞吐、单帧延迟和运行硬件将在模型产生稳定结果后单独评测，本文暂不把它们作为已经验证的性能结论。

算法使用固定六个 Tracker 槽位中当前可用的测量，以及过去 1 秒的已部署姿态、Tracker 状态和 Head 轨迹，预测当前帧 24 个关节在 Head-yaw 参考系中的全局旋转。核心方法是将可靠性感知的当前观测、Past-only 区域运动先验和当前 Head trajectory 按身体区域注入一个以 24 个关节为 token 的条件扩散模型，并在 DDIM 去噪过程中投影合法旋转与稳定 Tracker 旋转。最终通过 Head-anchored resolver 恢复 Actor Root 和世界空间关节结果，从而覆盖持续三点、持续六点、配置切换以及测量掉线与重连等在线状态。

本文按“问题定义 - 方法概览 - 核心机制 - 推理算法 - 训练与部署”的顺序组织。主文只保留理解算法所需的表示；稳定字段、精确形状和数据边界以仓库根目录的 [contract.md](../contract.md) 为准。

## 1. 问题定义与方法概览

### 1.1 在线重建任务

在在线帧 \(n\)，模型预测当前人体姿态 \(x_n\)。条件信息由三段过去历史和两类当前输入组成：

\[
p_\theta\!\left(
x_n\mid
\mathcal H_n^{pose},
\mathcal H_n^{tracker},
\mathcal H_n^{traj},
O_n,
\tau_n
\right).
\]

**式中：** \(p_\theta\) 表示参数为 \(\theta\) 的条件生成分布；\(n\) 表示在线帧编号；其余条件变量如下表所示。

| 变量 | 含义 |
|---|---|
| \(x_n\) | 当前帧完整人体姿态，是扩散模型的预测目标 |
| \(\mathcal H_n^{pose}\) | 过去 60 帧已部署姿态 |
| \(\mathcal H_n^{tracker}\) | 过去 60 帧 Tracker 测量与状态 |
| \(\mathcal H_n^{traj}\) | 过去 60 帧 Head 轨迹 |
| \(O_n\) | 当前帧 6 个 Tracker 的测量与可用状态 |
| \(\tau_n\) | 当前帧 Head 水平位移、朝向变化和高度控制 |

这里的“6 个 Tracker”指六个固定输入槽位，而不是要求六个设备始终有效。未配置或掉线的槽位保留状态字段，但测量字段为零。模型直接生成的是 144D 关节旋转；Actor Root 平移和世界空间关节位置由第 7 节的确定性解析恢复。

当前算法范围依赖以下前提：

- Head Tracker 始终配置且测量有效，并用于定义参考系、trajectory 和最终世界空间锚点；
- floor 高度与目标骨架参数已知；
- 当前训练场景只覆盖第 8.3 节列出的配置切换与掉线模式，暂不额外模拟测量噪声、重连跳变和其他掉线组合；
- 模型面向因果在线重建，任何历史编码都不能读取当前帧之后的信息。

历史条件与当前观测不是严格串行处理。历史分支负责产生运动先验，当前观测分支负责产生可靠性感知条件和 hard 集合，两者在同一帧内独立准备，随后共同参与 TargetDiT 去噪。

### 1.2 三个核心问题

该任务的困难不只是 Tracker 数量少，而是观测结构会随时间变化：

| 问题 | 直接后果 | 对应设计 |
|---|---|---|
| 动态稀疏观测 | 模型必须区分未配置、掉线、刚恢复和稳定测量 | 可靠性感知动态观测、连续 soft 权重和离散 hard gate |
| 欠观测运动生成 | 当前 Tracker 不能唯一确定完整人体姿态 | Past-only 区域运动先验 |
| 生成质量与部署可行性冲突 | 纯 soft 条件不能保证旋转合法或严格满足稳定测量 | Region-adaptive TargetDiT 与 Projected DDIM 中的 Soft-Hard 分工 |

由此形成四个相互配合的核心机制：

1. 用 Tracker 状态和连续有效时长估计测量可靠度；
2. 用过去姿态、Tracker 历史和 Head 轨迹提取区域化运动先验；
3. 在 TargetDiT 的每个 block 内按身体区域融合当前测量、运动先验和轨迹控制；
4. 在 DDIM 的 clean-pose estimate 上执行 SO(3) 与稳定 Tracker 旋转投影。

### 1.4 基础组件与当前架构的设计重点

标准扩散前向过程、DDIM 更新、rotation6D、SO(3) 和 FK 是基础组件。当前架构的设计重点是如何组织动态条件，以及如何把生成结果转换为可部署结果：

| 组件 | 职责 | 是否学习 |
|---|---|---:|
| Dynamic Observation Encoder | 分离 Tracker 状态、位置、旋转和历史摘要 | 是 |
| Tracker reliability 与 region coverage | 计算 \(\kappa\)、\(\rho\) 和 hard gate | 否 |
| Regional Motion Encoder | 从过去 60 帧提取四类区域运动先验 | 是 |
| Region-adaptive TargetDiT | 按关节和区域融合五类条件，直接预测 raw \(x_0\) pose | 是 |
| SO(3)/hard rotation projection | 保证旋转合法并满足稳定 Tracker 旋转 | 否 |
| Projected DDIM | 用投影后的 clean pose 推进下一去噪状态 | 否 |
| Head-anchored resolver | 将局部旋转结果恢复为世界空间结果 | 否 |

这种划分明确区分了三类信息：

- 当前测量是直接证据；
- 历史编码是学习得到的运动先验；
- hard projection 和世界解析是确定性部署约束。

## 2. 必要表示与时序约定

### 2.1 参考系

世界坐标系记为 \(W\)。当前局部参考系记为 \(C_n\)，其竖直轴与世界竖直轴一致，水平朝向由当前 Head yaw 决定，原点位于当前 Head 的水平位置与地面高度：

\[
o_n^W=
\begin{bmatrix}
p^W_{H,n,x} & floor_y & p^W_{H,n,z}
\end{bmatrix}^{\!\top}.
\]

**式中：** \(o_n^W\in\mathbb R^3\) 是当前局部参考系在世界坐标系中的原点；\(p^W_{H,n,x}\) 和 \(p^W_{H,n,z}\) 是第 \(n\) 帧 Head 世界位置的水平分量；\(floor_y\) 是当前地面世界高度；上标 \(W\) 表示变量表达在世界坐标系中。

令 \(R^W_{C_n}\in SO(3)\) 表示从 \(C_n\) 到 \(W\) 的旋转，则 Tracker 的局部测量为：

\[
p^{C_n}_{i,n}=(R^W_{C_n})^\top(p^W_{i,n}-o_n^W),
\qquad
R^{C_n}_{i,n}=(R^W_{C_n})^\top R^W_{i,n}.
\]

**式中：** \(i\) 是 Tracker 槽位编号；\(p^W_{i,n}\) 和 \(R^W_{i,n}\) 分别是该 Tracker 的世界位置与世界旋转；\(p^{C_n}_{i,n}\) 和 \(R^{C_n}_{i,n}\) 是转换后的局部位置与局部旋转；\(R^W_{C_n}\in SO(3)\) 把 \(C_n\) 中的向量旋转到 \(W\)，因此其转置 \((R^W_{C_n})^\top\) 完成反向旋转。

时间对齐遵循三条规则：

1. 当前姿态和当前 Tracker 表达在 \(C_n\)；
2. 过去姿态和过去 Tracker 历史统一表达在 \(C_{n-1}\)；
3. \(C_{n-1}\rightarrow C_n\) 的当前变化只通过当前 Head trajectory 输入模型。

Head forward 的水平投影接近零时，参考系沿用上一帧合法 yaw，避免朝向退化。

在线 runtime 缓存的是过去 deployed pose 和 Tracker 的世界空间状态，而不是直接缓存已经表达在某个旧局部系中的条件张量。在第 \(n\) 帧构造模型输入时，runtime 用第 \(n-1\) 帧的 Head 位置、yaw 和 floor 将整段姿态与 Tracker 历史重新编码到 \(C_{n-1}\)，再把当前观测单独编码到 \(C_n\)。因此，滚动窗口不会混合多个生成时刻的局部参考系。

闭环训练中不需要恢复完整世界状态，而是用相邻 Head yaw 的旋转差把旧姿态历史换到新的历史参考系：

\[
R^{C_n}_{j,t}
=
(R^W_{C_n})^\top R^W_{C_{n-1}}R^{C_{n-1}}_{j,t},
\qquad t\le n-1.
\]

**式中：** \(j\) 是骨架关节编号；\(t\) 是历史帧编号；\(R^{C_{n-1}}_{j,t}\) 是旧历史参考系中的关节全局旋转；\(R^{C_n}_{j,t}\) 是重表达后的旋转；\((R^W_{C_n})^\top R^W_{C_{n-1}}\) 是从旧 Head-yaw 参考系到新 Head-yaw 参考系的旋转。重表达完成后，窗口移除最早一帧，并追加已经位于 \(C_n\) 的上一帧 deployed pose。

### 2.2 144D 姿态目标

当前姿态由 24 个关节在 \(C_n\) 中的全局 rotation6D 顺序拼接：

\[
x_n\in\mathbb R^{144},
\qquad
144=24\ \text{joints}\times 6\ \text{rotation dimensions}.
\]

**式中：** \(x_n\) 是第 \(n\) 帧的干净姿态目标；24 是骨架关节数；每个关节使用 6 个实数表示一个三维旋转，因此目标总维度为 144。该目标只包含关节旋转，不直接包含 Actor Root 世界平移。

每个 rotation6D 由旋转矩阵的 forward 轴和 up 轴组成。姿态进入扩散模型前按训练集统计量逐维标准化；扩散状态记为：

\[
x_{n,k}\in\mathbb R^{144},
\]

**式中：** \(x_{n,k}\) 是第 \(n\) 个在线帧在扩散时间步 \(k\) 的标准化带噪姿态；\(k\in\{0,\ldots,K-1\}\)，其中 \(K\) 是实际采样时间步数，\(k=K-1\) 是采样起点，\(k=0\) 是最终去噪步。

当前实现固定采用 \(x_0\)-prediction。TargetDiT 在每个去噪步直接预测干净姿态，而不是直接预测噪声：

\[
\hat x_{n,k}^{0,raw}
=f_\theta\!\left(x_{n,k},k,\mathcal C_n\right).
\]

**式中：** \(f_\theta\) 表示参数为 \(\theta\) 的 TargetDiT；\(\mathcal C_n\) 汇总第 \(n\) 帧准备好的历史先验、当前观测和当前 trajectory 条件；\(\hat x_{n,k}^{0,raw}\) 是模型在第 \(k\) 个去噪步对干净姿态 \(x_n\) 的 raw estimate。

需要区分采样中间量与最终输出：

| 输出 | 含义 |
|---|---|
| Raw clean-pose estimate \(\hat x_{n,k}^{0,raw}\) | TargetDiT 在任一 DDIM step 的直接 \(x_0\) 预测 |
| Projected clean-pose estimate \(\hat x_{n,k}^{0,proj}\) | 中间步骤经 SO(3)/hard rotation 投影的 \(x_0\)，只用于推进采样 |
| Final raw pose \(\hat x_n^{raw}\) | 最终步投影前的模型预测，用于分析与几何监督 |
| Deployed pose \(\tilde x_n\) | 最终步投影后的部署结果，用于世界空间解析和历史更新 |

闭环训练和在线 rollout 写入下一帧历史的都是 deployed pose。

### 2.3 13D Tracker 观测

六个 Tracker 的固定顺序为：

\[
\{Head,\ Left\ Wrist,\ Right\ Wrist,\ Hip,\ Left\ Foot,\ Right\ Foot\}.
\]

**式中：** 集合中的顺序就是 13D 观测张量的固定 Tracker 槽位顺序；即使某个非 Head Tracker 未配置，其槽位也不会被删除或重排。

第 \(i\) 个 Tracker 的观测为：

\[
O_{i,n}=
\left[
y^p_{i,n},
y^R_{i,n},
c_{i,n},
v_{i,n},
\bar d^{off}_{i,n},
\bar d^{on}_{i,n}
\right]\in\mathbb R^{13}.
\]

**式中：** \(y^p_{i,n}\in\mathbb R^3\) 是局部位置；\(y^R_{i,n}\in\mathbb R^6\) 是局部 rotation6D；\(c_{i,n}\in\{0,1\}\) 表示是否配置；\(v_{i,n}\in\{0,1\}\) 表示当前测量是否有效；\(\bar d^{off}_{i,n}\) 和 \(\bar d^{on}_{i,n}\) 是写入网络输入的归一化连续掉线/有效时长。维度之和为 \(3+6+1+1+1+1=13\)。

原始 duration 以帧为单位，并在写入 13D 观测前按上限归一化：

\[
\bar d^{a}_{i,n}
=
\frac{\min(d^{a}_{i,n},D_{cap})}{D_{cap}},
\qquad a\in\{off,on\}.
\]

**式中：** \(d^{a}_{i,n}\) 是以帧为单位的原始连续时长；\(a\) 表示掉线 \(off\) 或有效 \(on\) 两种状态；\(D_{cap}\) 是 duration 截断上限，当前默认 60 帧；\(\bar d^{a}_{i,n}\in[0,1]\) 是实际进入网络的状态通道。第 3 节计算可靠度时使用恢复后的原始帧数 \(d^{on}_{i,n}\)。

进入 Dynamic Observation Encoder 前，只有 \(y^p\) 和 \(y^R\) 这前 9 个连续量按每个 Tracker 的训练集统计量标准化；\(c\)、\(v\)、\(\bar d^{off}\) 和 \(\bar d^{on}\) 不参与该统计。投影和几何损失另外保留前 9 维未标准化的 `current_tracker_raw`。无效测量在标准化前必须把位置与旋转严格清零。

| 状态 | \(c\) | \(v\) | duration 语义 |
|---|---:|---:|---|
| 未配置 | 0 | 0 | \(d^{off}=d^{on}=0\) |
| 已配置但掉线 | 1 | 0 | \(d^{off}\) 增加，\(d^{on}=0\) |
| 已配置且有效 | 1 | 1 | \(d^{on}\) 增加，\(d^{off}=0\) |

非 Head Tracker 测量无效时，位置和旋转必须清零，但状态和 duration 保留。Head 始终配置且测量有效；Head 位置不作为普通 position condition，而用于构造 trajectory 和最终世界空间解析。

### 2.4 5D Head trajectory

当前 Head trajectory 定义为：

\[
\tau_n=
\left[
\Delta x_n^{C_{n-1}},
\Delta z_n^{C_{n-1}},
h^{norm}_{head,n},
\sin\Delta\psi_n,
\cos\Delta\psi_n
\right].
\]

**式中：** \(\Delta x_n^{C_{n-1}}\) 和 \(\Delta z_n^{C_{n-1}}\) 是从第 \(n-1\) 帧到第 \(n\) 帧的 Head 世界位移在上一帧 Head-yaw 参考系中的水平分量；\(h^{norm}_{head,n}\) 是 Head 相对 floor 的标准化高度；\(\Delta\psi_n\) 是相邻两帧 Head yaw 的最短有符号差；正弦和余弦共同表示该角度，避免角度在 \(\pm\pi\) 处不连续。

过去 60 个 trajectory 只进入 Past-only Motion Encoder；当前 \(\tau_n\) 单独控制当前帧 TargetDiT，并在推理完成后才写入历史。冷启动首帧的水平位移与 yaw 增量置零，对应 \(\sin\Delta\psi=0\)、\(\cos\Delta\psi=1\)。

### 2.5 核心张量

| 输入 | 形状 | 参考系或语义 |
|---|---:|---|
| Diffusion state | [B,144] | 当前标准化姿态状态，位于 \(C_n\) |
| Pose history | [B,60,144] | 过去 deployed pose，位于 \(C_{n-1}\) |
| Tracker history | [B,60,6,13] | 过去 Tracker 测量与状态 |
| Current Tracker | [B,6,13] | 当前 Tracker 测量与状态，位于 \(C_n\) |
| Trajectory history | [B,60,5] | 过去 Head 逐帧运动，每个位移使用其上一帧 Head yaw 表达 |
| Current trajectory | [B,1,5] | 当前 Head 运动控制 |
| Valid frame mask | [B,60] | 标记冷启动历史中的真实有效帧 |

冷启动缺失历史在左侧补零，并通过 valid frame mask 排除。

## 3. 可靠性感知动态观测

### 3.1 分离“测量是什么”和“测量是否可信”

Dynamic Observation Encoder 把当前观测拆成三类 token，并单独汇总过去 Tracker 历史：

| 条件 | 输入 | 回答的问题 |
|---|---|---|
| State condition | \(c,v,\bar d^{off},\bar d^{on}\) | Tracker 是未配置、掉线、刚恢复还是稳定 |
| Position condition | 5 个非 Head Tracker 位置 | 哪些身体区域有直接位置证据 |
| Rotation condition | 6 个 Tracker 旋转 | 哪些关节朝向有直接旋转证据 |
| History summary | 过去 60 帧 Tracker | 最近状态变化和掉线前运动是什么 |

State condition 始终可见。Position 和 rotation condition 的可见性与强度由可靠度和区域覆盖度控制。History summary 只作为 Regional Motion Encoder 的历史上下文，不作为第六条当前条件分支直接写入 TargetDiT。

### 3.2 单 Tracker 可靠度

第 \(i\) 个 Tracker、模态 \(a\in\{p,R\}\) 的可靠度为：

\[
\kappa_{i,n}^{a}
=c_{i,n}v_{i,n}
\min\!\left(1,\frac{d^{on}_{i,n}}{D^a_{warm}}\right),
\qquad
\kappa_{i,n}^{a}\in[0,1].
\]

**式中：** \(\kappa_{i,n}^{a}\) 是第 \(n\) 帧 Tracker \(i\) 在模态 \(a\) 上的 soft 可靠度；\(a=p\) 表示位置模态，\(a=R\) 表示旋转模态；\(c_{i,n}\) 和 \(v_{i,n}\) 分别是配置状态与测量有效状态；\(d^{on}_{i,n}\) 是连续有效帧数；\(D^a_{warm}\) 是对应模态从重连到完全可信所需的 warm-up 帧数。

默认 \(D^p_{warm}=D^R_{warm}=15\) 帧：

- 未配置或掉线：\(\kappa=0\)，立即移除测量影响；
- 重连后第 1 至 14 个连续有效帧：\(\kappa\) 从 \(1/15\) 线性增加到 \(14/15\)；
- 连续有效达到 15 帧：\(\kappa=1\)。

在 attention 中，不被目标区域覆盖或 \(\kappa=0\) 的 Tracker key 被屏蔽；其余 key 使用 \(\log\kappa\) 形成可靠度偏置。实现中先将正可靠度截断到不小于 \(10^{-6}\) 再取对数，并单独屏蔽原始 \(\kappa=0\) 的 key，避免数值上的 \(\log 0\)。这样，可靠度既决定证据能否被读取，也影响多个可用 Tracker 之间的相对权重。

### 3.3 区域覆盖度

TargetDiT 将 24 个关节固定划分为五个目标区域：

\[
\mathcal R_{target}
=\{torso,\ left\ arm,\ right\ arm,\ left\ leg,\ right\ leg\}.
\]

**式中：** \(\mathcal R_{target}\) 是 TargetDiT 的目标区域集合；\(r\in\mathcal R_{target}\) 表示某个关节唯一所属的目标区域。24 个关节按下表恰好划入一个区域。

| 目标区域 | 包含关节 |
|---|---|
| torso | Pelvis、Spine1、Spine2、Spine3、Neck、Head、Left Collar、Right Collar |
| left arm | Left Shoulder、Left Elbow、Left Wrist、Left Hand |
| right arm | Right Shoulder、Right Elbow、Right Wrist、Right Hand |
| left leg | Left Hip、Left Knee、Left Ankle、Left Foot |
| right leg | Right Hip、Right Knee、Right Ankle、Right Foot |

固定矩阵 \(A^a_{r,i}\in\{0,1\}\) 表示 Tracker \(i\) 是否覆盖区域 \(r\) 的模态 \(a\)。当前覆盖关系为：

| 目标区域 | 位置覆盖 Tracker | 旋转覆盖 Tracker |
|---|---|---|
| torso | Hip | Head、Hip |
| left arm | Left Wrist | Left Wrist |
| right arm | Right Wrist | Right Wrist |
| left leg | Left Foot | Left Foot |
| right leg | Right Foot | Right Foot |

区域覆盖度由可用 Tracker 可靠度聚合：

\[
\rho_{r,n}^{a}
=1-\prod_i\left(1-A^a_{r,i}\kappa_{i,n}^{a}\right),
\qquad
\rho_{r,n}^{a}\in[0,1].
\]

**式中：** \(\rho_{r,n}^{a}\) 是第 \(n\) 帧目标区域 \(r\) 在模态 \(a\) 上的聚合覆盖度；\(A^a_{r,i}=1\) 表示 Tracker \(i\) 的该模态被允许覆盖区域 \(r\)，否则为 0；\(\kappa_{i,n}^{a}\) 是单 Tracker 可靠度；乘积遍历六个固定 Tracker 槽位。该 noisy-OR 形式允许同一区域的多个可靠 Tracker 共同提高覆盖度。

\(\rho=0\) 表示该区域没有当前直接证据，\(\rho=1\) 表示至少存在完全可靠的直接证据。TargetDiT 用 \(\rho^p\) 和 \(\rho^R\) 分别控制 position 和 rotation 条件分支的写入强度。

### 3.4 Soft 可靠度与 hard gate

Soft 条件允许恢复期测量逐渐影响生成；hard gate 只在测量连续稳定后启用。除 Head 外，第 \(i\) 个 Tracker 的旋转 hard gate 为：

\[
h^R_{i,n}
=c_{i,n}v_{i,n}\,
\mathbb 1[d^{on}_{i,n}\ge D_h],
\qquad
h^R_{i,n}\in\{0,1\}.
\]

**式中：** \(h^R_{i,n}\) 是 Tracker \(i\) 在第 \(n\) 帧的旋转 hard gate；\(\mathbb 1[\cdot]\) 是指示函数，条件成立时取 1，否则取 0；\(D_h\) 是启用 hard rotation projection 所需的连续有效帧阈值；其余符号与可靠度公式一致。

默认 \(D_h=15\) 帧，且 Head 始终满足 \(h^R_{Head,n}=1\)。

| Tracker 状态 | \(\kappa\) | \(h^R\) | 行为 |
|---|---:|---:|---|
| 未配置或掉线 | 0 | 0 | 不读取当前测量，只依赖历史与运动先验 |
| 重连 1 至 14 帧 | \((0,1)\) | 0 | 只通过 soft 条件逐渐恢复影响 |
| 连续稳定至少 15 帧 | 1 | 1 | 使用完整 soft 条件，并启用旋转 hard projection |

本帧 hard 集合在整个 DDIM 采样过程中保持不变，不根据中间去噪结果切换。

## 4. Past-only 区域运动先验

### 4.1 为什么先验只能读取过去

当前 Tracker 和当前 trajectory 已经作为当前帧条件进入 TargetDiT。如果它们再次进入 Motion Encoder，先验分支就可以借助当前条件走捷径，重复编码当前证据，并削弱“历史运动先验”和“当前测量证据”的职责边界。这里的 Past-only 限制是结构上的条件分工，不是把当前 Tracker 视为非法信息。

因此 Regional Motion Encoder 严格只读取：

- 过去 60 帧 deployed pose；
- 过去 Tracker 的 GRU 历史摘要；
- 过去 60 帧 Head trajectory；
- valid frame mask。

### 4.2 四类运动区域

Motion Encoder 使用四类运动先验：

\[
\mathcal R_{motion}
=\{global,\ pelvis,\ left\ leg,\ right\ leg\}.
\]

**式中：** \(\mathcal R_{motion}\) 是 Regional Motion Encoder 的先验区域集合；global 使用全部 24 个关节，pelvis 使用躯干与骨盆链，left leg 和 right leg 分别使用对应侧四个腿部关节。该集合与五类 \(\mathcal R_{target}\) 不同。

每个历史帧先按区域提取姿态，再与 trajectory token 和该区域可访问的 Tracker 历史摘要相加。四条区域序列分别通过带 causal mask 的时序 Transformer，输出：

| 运动先验区域 | 可读取的 Tracker 历史摘要 |
|---|---|
| global | 全部六个 Tracker |
| pelvis | Head、Hip |
| left leg | Head、Hip、Left Foot |
| right leg | Head、Hip、Right Foot |

\[
M^{temp}\in\mathbb R^{B\times4\times60\times D},
\qquad
M^{latent}\in\mathbb R^{B\times4\times D}.
\]

**式中：** \(M^{temp}\) 是保留时间轴的区域运动 token；\(M^{latent}\) 是每个区域最后一个有效历史帧对应的汇总 latent；\(B\) 是 batch size；4 对应四类运动先验；60 是历史帧数；\(D\) 是模型 latent 维度，默认 512。

时间特征保留过去 60 帧的局部变化，汇总特征取最后一个有效历史帧；冷启动没有有效历史时对应输出为零。

### 4.3 先验访问关系

四类 Motion Encoder 区域与五类 TargetDiT 目标区域不是同一个概念。每个目标区域只能读取与其运动职责相关的先验：

| TargetDiT 目标区域 | 可读取的运动先验 |
|---|---|
| torso | global、pelvis |
| left arm | global |
| right arm | global |
| left leg | global、pelvis、left leg |
| right leg | global、pelvis、right leg |

其中 global 表示动作类型、节奏和全身协调；pelvis 表示重心与躯干-骨盆协调；左右腿先验分别表示对应腿部的相位、支撑状态和短期变化。

## 5. 显式条件路由与 Region-adaptive TargetDiT

### 5.1 关节 token 与目标区域

TargetDiT 将扩散状态 \(x_{n,k}\) 拆为 24 个 joint token。每个 token 由三部分相加得到：

1. 当前关节的 6D 扩散状态投影；
2. 关节身份 embedding；
3. 身体区域身份 embedding。

初始 joint token 可写为：

\[
z_j^{(0)}
=W_x x_{n,k}^{(j)}+e_j^{joint}+e_{r(j)}^{region}.
\]

**式中：** \(z_j^{(0)}\in\mathbb R^D\) 是进入第一个 TargetDiT block 的关节 \(j\) token；\(x_{n,k}^{(j)}\in\mathbb R^6\) 是扩散状态中属于该关节的 rotation6D；\(W_x\) 是从 6 维到 \(D\) 维的学习投影；\(e_j^{joint}\) 是关节身份 embedding；\(e_{r(j)}^{region}\) 是关节所属目标区域 \(r(j)\) 的 embedding。

区域函数 \(r(j)\) 使用第 3.3 节的固定五区域划分，把每个关节唯一映射到 torso、left arm、right arm、left leg 或 right leg。它既提供区域身份 embedding，也是后续全部条件路由从目标区域落到具体 joint token 的最后一级映射。

### 5.2 显式分层条件路由

TargetDiT 接收的不是未经组织的条件集合。模型不允许所有条件无差别地作用于全部关节，也不完全依赖 attention 自行学习 Tracker、运动先验、身体区域和关节之间的对应关系。相反，模型先显式定义条件的可达拓扑，再在允许的路径内用 attention 学习内容匹配。

直观上，每个 joint token 都有一张由其身体区域决定的“条件可见列表”：路由允许的 Tracker 和运动先验可以被该 token 读取，未被路由到该区域的条件在 attention 中不可见。可以把整个过程概括为：路由决定“能看谁”，attention 决定“从可见条件中读到什么”，gate 决定“读取结果最终影响多大”。

例如，Left Knee 属于 left-leg 区域，因此它可以读取始终全局可见的 Tracker state、Left Foot 的位置与旋转条件，以及 global、pelvis 和 left-leg motion prior；它不能读取 Right Foot 的位置与旋转条件，也不能读取 right-leg motion prior。当 Left Foot 掉线时，固定路由拓扑不变，但对应 \(\kappa\) 变为 0，使该 Tracker measurement key 在 attention 中不可见；同时 left-leg 区域的 \(\rho\) 降低、\(g^{prior}\) 增大，使 Left Knee 更多依赖历史运动先验。

同一区域的关节拥有相同的条件可见范围和区域级 gate，但它们的 joint identity、当前扩散状态和 attention query 不同，因此从同一组可见条件中读取到的具体内容仍然可以不同。

整个路由过程分为三个层级：

1. 第 3、4 节把当前观测与历史运动编码为不同语义的条件 memory；
2. 固定语义路由决定每类条件 memory 能够到达哪些目标区域；
3. 区域函数 \(r(j)\) 把目标区域条件分发给对应 joint token。

路由拓扑由固定的身体语义关系决定，路径的有效性与写入强度则由 Tracker 可靠度、valid frame mask、区域覆盖度和各类区域 gate 控制。允许路径内的 attention 参数仍然参与学习，因此这里采用的是“固定拓扑、动态强度、路径内学习”，而不是 learned router 或 MoE routing。

~~~mermaid
flowchart LR
    CUR["当前 Tracker i"] --> OBS["State / Position / Rotation tokens"]
    OBS -->|"State：全局可见"| JOINT["Joint token j"]
    OBS -->|"A 与 kappa：Tracker → 目标区域"| TARGET["Target region r"]
    TARGET -->|"r(j)：目标区域 → 关节"| JOINT

    TH["Tracker history i"] -->|"B_hist：Tracker → 运动区域"| MOTION["Motion region m"]
    PH["Pose history"] -->|"P_hist：关节 → 运动区域"| MOTION
    TRH["Trajectory history"] --> MOTION
    MOTION -->|"G_prior：运动区域 → 目标区域"| TARGET

    CURTR["Current trajectory"] -->|"gamma：trajectory → 目标区域"| TARGET
    CUR -->|"T_hard 与 hard gate"| PROJ["第 6 节 clean-pose projection"]
~~~

路由关系统一如下：

| 路由对象 | 固定可达拓扑 | 路由强度或有效性 | 最终去向 |
|---|---|---|---|
| Tracker state | 全连接状态路由 \([24,6]\) | 始终可见，无额外可靠度 gate | TargetDiT state branch |
| 当前 Tracker 位置/旋转 → 目标区域 | \(A^p,A^R\in\{0,1\}^{5\times6}\) 与 \(r(j)\) | \(\kappa^p,\kappa^R\) 控制 key；\(\rho^p,\rho^R\) 控制区域写回 | Position/rotation branch |
| Tracker history → 运动区域 | \(B^{hist}\in\{0,1\}^{4\times6}\) | valid frame mask | Regional Motion Encoder |
| Pose history → 运动区域 | \(P^{hist}\in\{0,1\}^{4\times24}\) | valid frame mask | Regional Motion Encoder |
| 运动区域 → 目标区域 | \(G^{prior}\in\{0,1\}^{5\times4}\) 与 \(r(j)\) | \(g^{prior}_{r,n}\) 控制区域写回 | Past-prior branch |
| Current trajectory → 目标区域 | \(r(j)\) | \(\gamma_r\) 为固定区域强度，当前 \(\tau_n\) 决定写入内容 | Trajectory branch |
| 稳定 Tracker 旋转 → 对应关节 | \(T^{hard}\in\{0,1\}^{6\times24}\) | \(h^R_{i,n}\) 决定路径是否激活 | 第 6 节 hard projection |

表中的 \(B^{hist}\)、\(P^{hist}\)、\(G^{prior}\) 和 \(T^{hard}\) 是对现有固定索引表与 attention mask 的统一数学记号；实现可以继续使用关节索引、Tracker 索引和布尔 mask，不要求额外引入可学习路由参数。

#### 5.2.1 当前观测的 Tracker-to-region-to-joint 路由

Tracker state token 表示“测量是否存在以及处于什么状态”，因此六个 state token 对全部 24 个 joint token 始终可见。位置和旋转测量则使用显式的区域可达关系。对于模态 \(a\in\{p,R\}\)，关节 \(j\) 能否读取 Tracker \(i\) 由下式决定：

\[
\Omega^a_{j,i}
=A^a_{r(j),i}.
\]

**式中：** \(\Omega^a_{j,i}\in\{0,1\}\) 是模态 \(a\) 下 Tracker \(i\) 到关节 \(j\) 的显式路由；\(r(j)\) 是关节所属目标区域；\(A^a_{r,i}\) 是第 3.3 节定义的 Tracker-to-target-region coverage。\(\Omega=0\) 表示该 Tracker key 对该关节不可达。

固定拓扑与逐帧可靠度共同形成 attention bias：

\[
b^a_{j,i,n}
=
\begin{cases}
\log\kappa^a_{i,n},
& \Omega^a_{j,i}=1\ \text{且}\ \kappa^a_{i,n}>0,\\
-\infty,
& \text{其他情况}.
\end{cases}
\]

**式中：** \(b^a_{j,i,n}\) 是第 \(n\) 帧关节 \(j\) 读取 Tracker \(i\) 时的 attention bias；\(\kappa^a_{i,n}\) 是单 Tracker soft 可靠度。固定矩阵 \(A^a\) 决定路径是否存在，\(\kappa^a\) 决定允许路径内单个 Tracker key 的读取强度，\(\rho^a\) 则在 attention 后控制整个区域分支的写回强度。

因此，当前测量路由具有三个不同层级：

- \(A^a\) 控制“Tracker 是否能够影响该区域”；
- \(\kappa^a\) 控制“沿允许路径应当多信任该 Tracker”；
- \(\rho^a\) 控制“该模态最终向目标区域写入多少”。

#### 5.2.2 历史先验的两阶段区域路由

历史条件首先在 Regional Motion Encoder 内部从源信息路由到四个运动区域。令 \(B^{hist}_{m,i}\in\{0,1\}\) 表示运动区域 \(m\) 是否读取 Tracker \(i\) 的历史摘要，则区域 Tracker 上下文为：

\[
C^{tracker}_{m,n}
=W_m^{tracker}
\left(
\frac{
\sum_i B^{hist}_{m,i}H^{tracker}_{i,n}
}{
\sum_i B^{hist}_{m,i}
}
\right).
\]

**式中：** \(H^{tracker}_{i,n}\in\mathbb R^D\) 是 Dynamic Observation Encoder 为 Tracker \(i\) 汇总的过去 60 帧 GRU history summary；\(B^{hist}_{m,i}\) 是第 4.2 节访问表对应的固定 Tracker-to-motion-region 路由；\(W_m^{tracker}\) 是运动区域 \(m\) 独立的学习投影；\(C^{tracker}_{m,n}\) 是写入该运动区域序列的 Tracker 历史上下文。

Pose history 使用固定矩阵 \(P^{hist}_{m,j}\) 选择属于 global、pelvis、left leg 或 right leg 的历史关节。Trajectory history 对四个运动区域均可见。三类历史信息在每个运动区域内融合后，产生第 4.2 节的 \(M_m^{temp}\) 和 \(M_m^{latent}\)。

随后进行第二阶段路由：四个运动区域通过固定矩阵 \(G^{prior}_{r,m}\) 路由到五个 TargetDiT 目标区域。关节 \(j\) 是否能够读取运动区域 \(m\) 为：

\[
\Omega^{prior}_{j,m}
=G^{prior}_{r(j),m}.
\]

**式中：** \(\Omega^{prior}_{j,m}\in\{0,1\}\) 是运动区域 \(m\) 到关节 \(j\) 的先验路由；\(G^{prior}_{r,m}\) 对应第 4.3 节的 motion-to-target 访问关系；历史 temporal token 还必须同时满足 valid frame mask。冷启动时 temporal token 全部被屏蔽，始终保留的 latent token 取零值。

因此，历史先验的完整路径为：

\[
\{Pose,Tracker,Trajectory\}\ history
\longrightarrow
Motion\ region\ m
\longrightarrow
Target\ region\ r(j)
\longrightarrow
Joint\ j.
\]

**式中：** 第一段路由在 Regional Motion Encoder 内构造语义不同的运动 memory，第二段路由在 TargetDiT 中限制每个目标区域可以读取哪些运动 memory，最后由 \(r(j)\) 把区域先验分发到具体 joint token。

#### 5.2.3 Current trajectory route 与 hard bypass

Current trajectory 不作为普通 cross-attention memory，而是先编码为一个 trajectory token，再产生共享的 shift 和 scale。对关节 \(j\) 的 trajectory 条件值为：

\[
U_j^{(\ell)}
=\delta_n^{traj,(\ell)}
+s_n^{traj,(\ell)}\odot Q_j^{(\ell)}.
\]

**式中：** \(Q_j^{(\ell)}\) 是第 \(\ell\) 个 block 中关节 \(j\) 的归一化条件 query；\(\delta_n^{traj,(\ell)}\) 和 \(s_n^{traj,(\ell)}\) 是第 \(\ell\) 个 block 用自身 trajectory modulation 层从当前 trajectory token 产生的 feature-wise shift 与 scale；\(\odot\) 表示逐维乘法；\(U_j^{(\ell)}\) 再通过 \(\gamma_{r(j)}\) 按目标区域控制写入强度。

旋转 hard gate 使用独立的 bypass route：

\[
\Omega^{hard}_{i,j,n}
=h^R_{i,n}T^{hard}_{i,j}.
\]

**式中：** \(T^{hard}_{i,j}\in\{0,1\}\) 是第 6.2 节的固定 Tracker-to-joint 映射；\(h^R_{i,n}\) 决定本帧是否激活该路径；\(\Omega^{hard}_{i,j,n}=1\) 时，Tracker \(i\) 的旋转在 clean-pose projection 中替换关节 \(j\) 的全局旋转。该路径不进入 TargetDiT，也不参与下面的 soft 条件融合。

同一在线帧内，Dynamic Observation Encoder、Regional Motion Encoder 和 current trajectory encoder 只准备一次条件 memory、路由 mask 和动态 gate，并在全部 DDIM steps 间复用。不同 DDIM step 和不同 TargetDiT block 使用相同的条件与路由拓扑，但 joint query 会随扩散状态和 block 深度变化，因此允许路径内的 attention 读取结果仍然动态变化。

### 5.3 路径约束下的条件读取与融合

每个 TargetDiT block 使用同一个归一化 joint-token 输入作为共同 query，沿第 5.2 节允许的路径独立读取五类条件：

| 条件分支 | Key/value memory | 路径约束 | 输出强度 |
|---|---|---|---|
| Tracker state | \(E_n^S\in\mathbb R^{B\times6\times D}\) | 对全部 joint token 可见 | 始终写入 |
| Tracker position | \(E_n^p\in\mathbb R^{B\times5\times D}\) | \(A^p\) 与 \(b^p\) | \(\rho^p\) |
| Tracker rotation | \(E_n^R\in\mathbb R^{B\times6\times D}\) | \(A^R\) 与 \(b^R\) | \(\rho^R\) |
| Past motion prior | \(\mathcal M_n\in\mathbb R^{B\times244\times D}\) | \(G^{prior}\) 与 valid frame mask | \(g^{prior}\) |
| Current trajectory | 当前 \(\tau_n\) 的 shift/scale | \(r(j)\) | \(\gamma_{r(j)}\) |

共同 query 为：

\[
Q^{(\ell)}
=\operatorname{LN}_{cond}\!\left(z^{(\ell)}\right).
\]

**式中：** \(z^{(\ell)}\in\mathbb R^{B\times24\times D}\) 是第 \(\ell\) 个 block 的 joint-token 输入；\(\operatorname{LN}_{cond}\) 是五个条件分支共享的无仿射 LayerNorm；\(Q^{(\ell)}\) 是全部 24 个关节的共同条件 query。

Past-prior memory 把每个运动区域的 60 个 temporal token 与 1 个 latent token 拼接，再展平四个运动区域：

\[
\mathcal M_n
=\operatorname{Flatten}_{m,t}
\left(
\operatorname{Concat}_{t}
\left[M_n^{temp},M_n^{latent}[:,:,None,:]\right]
\right)
\in\mathbb R^{B\times244\times D}.
\]

**式中：** \(\mathcal M_n\) 是 prior cross-attention 的统一 key/value memory；每个运动区域提供 \(60+1=61\) 个 token，四个区域共 \(4\times61=244\) 个 token；路由 mask 保留 token 的运动区域身份，因此展平不会取消第 5.2 节的区域访问约束。

四个条件读取分支可写为：

\[
\begin{aligned}
C^{S,(\ell)}
&=\operatorname{Attn}\!\left(Q^{(\ell)},E_n^S,E_n^S\right),\\
C^{p,(\ell)}
&=\operatorname{Attn}\!\left(Q^{(\ell)},E_n^p,E_n^p;b_n^p\right),\\
C^{R,(\ell)}
&=\operatorname{Attn}\!\left(Q^{(\ell)},E_n^R,E_n^R;b_n^R\right),\\
C^{M,(\ell)}
&=\operatorname{Attn}\!\left(Q^{(\ell)},\mathcal M_n,\mathcal M_n;b_n^{prior}\right).
\end{aligned}
\]

**式中：** \(C^S\)、\(C^p\)、\(C^R\) 和 \(C^M\) 分别是 state、position、rotation 和 past-prior cross-attention 的输出；attention 的第一个参数是 query，后两个参数分别是 key 和 value；\(b_n^p\) 与 \(b_n^R\) 由 Tracker-to-region 路由和 \(\log\kappa\) 共同构造；\(b_n^{prior}\) 由 motion-to-target 路由和 valid frame mask 构造。

五类条件最终一次性写回 residual state：

\[
\bar z_j^{(\ell)}
=z_j^{(\ell)}
+C_j^{S,(\ell)}
+\rho^p_{r(j),n}C_j^{p,(\ell)}
+\rho^R_{r(j),n}C_j^{R,(\ell)}
+g^{prior}_{r(j),n}C_j^{M,(\ell)}
+\gamma_{r(j)}U_j^{(\ell)}.
\]

**式中：** \(\bar z_j^{(\ell)}\) 是条件融合后的关节 token；四个 \(C\) 分别来自路径约束下的 cross-attention；\(U_j^{(\ell)}\) 是 current trajectory 的特征调制值；\(\rho^p\)、\(\rho^R\)、\(g^{prior}\) 和 \(\gamma\) 分别控制对应分支写回目标区域的强度。

所有条件分支都读取同一个 \(Q^{(\ell)}\)，并在全部分支计算完成后一次性写回。这样，某个条件分支不会先改变其他分支的 attention query，路由和 gate 只控制其对应证据。

### 5.4 观测与先验的自适应分工

运动先验门控为：

\[
g^{prior}_{r,n}
=\max\!\left(
0.1,
1-\frac{\rho^p_{r,n}+\rho^R_{r,n}}{2}
\right).
\]

**式中：** \(g^{prior}_{r,n}\in[0.1,1]\) 是第 \(n\) 帧区域 \(r\) 的运动先验写入强度；\(\rho^p_{r,n}\) 和 \(\rho^R_{r,n}\) 分别是该区域的位置与旋转覆盖度；常数 0.1 是当前实现的先验保留下限。

因此：

- 当前直接观测不足时，区域运动先验自动增强；
- 当前观测充分时，模型优先服从测量；
- 即使 \(\rho^p=\rho^R=1\)，仍保留 0.1 的先验，维持全身协调。

当前 trajectory 的区域系数 \(\gamma_r\) 为：

| torso | left arm | right arm | left leg | right leg |
|---:|---:|---:|---:|---:|
| 1.0 | 0.25 | 0.25 | 1.0 | 1.0 |

这使 Head 运动主要控制躯干和双腿，手臂更多服从手腕测量与 global motion prior。

### 5.5 Block 更新与模型输出

条件融合得到 \(\bar z^{(\ell)}\) 后，block 再执行扩散时间调制的 self-attention 和 MLP：

\[
q^{sa}=\operatorname{AdaLN}\!\left(\operatorname{LN}_{sa}(\bar z^{(\ell)});e_k^{time}\right),
\qquad
z^{sa}=\bar z^{(\ell)}+g_{sa}(e_k^{time})\operatorname{SelfAttn}(q^{sa}),
\]

**式中：** \(\operatorname{LN}_{sa}\) 是 self-attention 前的 LayerNorm；\(e_k^{time}\) 是扩散时间步 \(k\) 的 embedding；\(\operatorname{AdaLN}(\cdot;e_k^{time})\) 使用该 embedding 产生 shift 和 scale；\(g_{sa}(e_k^{time})\) 是 AdaLN-Zero 产生的 self-attention residual gate；\(z^{sa}\) 是 self-attention 更新后的全部 joint token。

\[
z^{(\ell+1)}
=z^{sa}
+g_{mlp}(e_k^{time})\operatorname{MLP}\!\left(
\operatorname{AdaLN}\!\left(\operatorname{LN}_{mlp}(z^{sa});e_k^{time}\right)
\right).
\]

**式中：** \(\operatorname{LN}_{mlp}\) 是 MLP 前的 LayerNorm；\(g_{mlp}(e_k^{time})\) 是扩散时间生成的 MLP residual gate；\(z^{(\ell+1)}\) 是传给下一个 block 的 token。两个 AdaLN 分支共使用由时间 embedding 一次生成的六组 shift、scale 和 gate 参数。

TargetDiT 的主去噪头输出 raw 144D \(x_0\)。训练时以及采样的最终 \(k=0\) 步，模型还从最终 joint token 产生两个辅助输出：future-leg 为 \([B,3,8,6]\)，预测未来 3 帧、8 个腿部关节的 rotation6D；contact logits 为 \([B,2]\)，对应当前帧左右脚接触。两个辅助头不改变 DDIM 状态，也不参与 Head-anchored resolver；它们目前作为训练监督和可选运行时输出。

## 6. Soft-Hard 旋转约束与 Projected DDIM

### 6.1 Soft-Hard 原则

> 只有能够低成本、稳定并以闭式形式满足的约束才进入 Hard；其余证据通过可靠性感知的 Soft conditioning 参与生成。

位置测量、恢复期旋转和历史运动属于 soft 证据。合法 SO(3) 旋转以及连续稳定 Tracker 的对应关节旋转属于 hard 约束。

### 6.2 Clean-pose projection

TargetDiT 的 raw clean-pose estimate 通过统一投影算子：

\[
\hat x_{n,k}^{0,proj}
=\mathcal P_R\!\left(
\hat x_{n,k}^{0,raw};
O_n^{R,raw},
h_n^R
\right).
\]

**式中：** \(\mathcal P_R\) 是旋转投影算子；\(\hat x_{n,k}^{0,raw}\) 是 TargetDiT 对干净姿态的直接预测；\(\hat x_{n,k}^{0,proj}\) 是当前去噪步的投影结果；\(O_n^{R,raw}\) 是第 \(n\) 帧六个 Tracker 在 \(C_n\) 中、尚未按训练统计量标准化的 rotation6D；\(h_n^R\in\{0,1\}^6\) 是本帧固定的 hard rotation gate。

\(\mathcal P_R\) 依次执行：

1. 将标准化预测还原到原始 rotation6D 空间；
2. 对全部 24 个关节执行稳定 Gram-Schmidt：归一化 forward 轴，从 up 轴中移除 forward 分量，再通过叉乘恢复右手正交基；退化输入使用固定备用轴；
3. 对 \(h^R_{i,n}=1\) 的 Tracker，用当前 Tracker 旋转替换对应关节的全局旋转；
4. 重新编码为 rotation6D 并返回标准化扩散空间。

Tracker 与被替换关节的固定映射为：

| Tracker | Head | Left Wrist | Right Wrist | Hip | Left Foot | Right Foot |
|---|---|---|---|---|---|---|
| 对应关节 | Head | Left Wrist | Right Wrist | Pelvis | Left Foot | Right Foot |

位置测量不进入 hard projection，因为直接强制关节位置通常需要 IK 或约束优化，不能像全局旋转替换一样以低成本闭式完成。

投影满足幂等性：

\[
\mathcal P_R(\mathcal P_R(x))=\mathcal P_R(x).
\]

**式中：** \(x\) 表示任意 144D 姿态；幂等性表示在 Tracker 旋转和 hard gate 固定时，对已经投影的姿态再次应用 \(\mathcal P_R\) 不会继续改变结果。实际浮点实现允许数值舍入误差。

### 6.3 用 projected \(x_0\) 推进 DDIM

关键点不是只在最终输出上覆盖 Tracker 旋转，而是用 projected clean-pose estimate 重新计算当前步噪声。

根据投影模式，当前 DDIM step 实际采用的 clean-pose estimate 记为：

\[
\bar x_{n,k}^{0}
=
\begin{cases}
\hat x_{n,k}^{0,proj}, & \text{第 }k\text{ 步启用投影},\\
\hat x_{n,k}^{0,raw}, & \text{第 }k\text{ 步不启用投影}.
\end{cases}
\]

**式中：** \(\bar x_{n,k}^{0}\) 是真正用于计算本步 DDIM 更新的 \(x_0\) estimate；all_steps 模式在每一步选择 projected estimate；late_steps 只在最后若干步选择 projected estimate；final_step 只在 \(k=0\) 选择 projected estimate。

给定扩散状态 \(x_{n,k}\) 和累计噪声系数 \(\bar\alpha_k\)，先计算：

\[
\epsilon_k
=
\frac{x_{n,k}-\sqrt{\bar\alpha_k}\bar x_{n,k}^{0}}
{\sqrt{1-\bar\alpha_k}}.
\]

**式中：** \(\epsilon_k\) 是由当前带噪状态和选定的 clean-pose estimate 反推出的噪声；\(x_{n,k}\) 是第 \(n\) 帧的当前扩散状态；\(\bar\alpha_k=\prod_{s=0}^{k}\alpha_s\) 是前向扩散保留信号的累计系数；\(\alpha_s=1-\beta_s\)，其中 \(\beta_s\) 是第 \(s\) 步的噪声 schedule 系数。

随后按 DDIM 更新：

\[
\sigma_k
=
\eta
\sqrt{\frac{1-\bar\alpha_{k-1}}{1-\bar\alpha_k}}
\sqrt{1-\frac{\bar\alpha_k}{\bar\alpha_{k-1}}},
\]

**式中：** \(\sigma_k\) 是从第 \(k\) 步更新到第 \(k-1\) 步时额外注入噪声的标准差；\(\eta\ge0\) 控制 DDIM 的随机程度；\(\bar\alpha_k\) 和 \(\bar\alpha_{k-1}\) 分别是当前与下一去噪状态的累计信号系数。该式只在 \(k>0\) 时使用。

\[
x_{n,k-1}
=
\sqrt{\bar\alpha_{k-1}}\bar x_{n,k}^{0}
+
\sqrt{1-\bar\alpha_{k-1}-\sigma_k^2}\epsilon_k
+
\sigma_k z,
\qquad z\sim\mathcal N(0,I).
\]

**式中：** \(x_{n,k-1}\) 是更新后的下一去噪状态；第一项写入当前 clean-pose estimate，第二项保留由该 estimate 反推的噪声方向，第三项注入可选随机噪声；\(z\) 是与姿态同形的标准高斯噪声；\(I\) 是 144 维单位协方差矩阵。

在线默认 \(\eta=0\)，因此给定初始噪声 \(x_{n,K-1}\) 和条件后，全部 DDIM 更新是确定的。当前 runtime 在未显式传入初始噪声时仍会为每帧采样新的标准高斯噪声，所以“\(\eta=0\)”不等同于整个在线调用天然无随机性；需要完全可重复时还必须固定或显式提供初始噪声。

### 6.4 Algorithm 1：Projected DDIM

~~~text
输入：
    当前帧准备好的条件 C_n
    本帧固定 hard rotation gate h_n^R
    当前原始 Tracker 旋转 O_n^{R,raw}
    投影模式 mode
    实际采样时间步数 K

x_{n,K-1} <- 标准高斯噪声，或调用方显式给定的初始噪声

for k = K-1, ..., 0:
    raw_x0 <- TargetDiT(x_{n,k}, k, C_n)
    projected_x0 <- P_R(raw_x0; O_n^{R,raw}, h_n^R)

    if mode 要求在第 k 步投影:
        step_x0 <- projected_x0
    else:
        step_x0 <- raw_x0

    epsilon_k <- 由 x_{n,k} 和 step_x0 重新计算

    if k > 0:
        x_{n,k-1} <- DDIM(step_x0, epsilon_k, k)
    else:
        final_raw_pose <- raw_x0
        deployed_pose <- projected_x0

返回 final_raw_pose、deployed_pose 与最终步辅助输出
~~~

默认 \(K=50\)，噪声 schedule 为 cosine，投影模式为 all_steps，即每个去噪步都投影。`ts_respace` 可以改变实际采样时间步集合。late_steps 和 final_step 是可选比较模式；所有支持模式在最终步都返回 projected deployed pose。

Projected DDIM 约束的是每一步 clean-pose estimate，而不是带噪状态 \(x_{n,k}\) 本身。它保证部署可行性，但不声称得到严格的条件后验样本。

## 7. 世界空间恢复与在线推理

### 7.1 Head-anchored 世界空间解析

扩散模型只预测 \(C_n\) 中 24 个关节的全局旋转，不直接预测 Actor Root 世界平移。最终 deployed pose 通过 Head-anchored resolver 恢复世界结果：

1. 以 Pelvis 为原点执行一次 FK，得到 Head 相对 Pelvis 的位置；
2. 用观测 Head 高度减去 FK 中的 Head 相对高度，得到 Pelvis 高度；
3. 以预测 Pelvis 的水平朝向作为 Actor Root yaw；
4. 对齐 FK Head 与观测 Head 世界位置，得到 Actor Root 水平平移。

Actor Root 的竖直位置固定为：

\[
p^W_{root,y}=floor_y.
\]

**式中：** \(p^W_{root,y}\) 是 Actor Root 世界位置的竖直分量；\(floor_y\) 是当前帧已知的地面世界高度。Pelvis 的实际高度由 Head 锚定的 FK 几何恢复，不与这个位于地面的 Actor Root 节点混为一谈。

最终输出包括 Actor Root 世界位置和 yaw、Pelvis 高度、24 个世界关节位置与旋转，以及 Unity local rotation。

Resolver 在推理阶段只执行一次确定性 FK，不包含 IK、迭代优化或任何基于梯度的在线求解。训练阶段的 FK、Root 和世界关节几何损失仍可通过可微 FK 与 resolver 回传到姿态网络。Root 精度仍受姿态预测、目标骨架尺寸和 HMD 世界定位误差影响。

### 7.2 单帧在线流程

每个在线帧按以下顺序执行：

1. 从世界空间缓存重建历史条件：将过去 deployed pose 和 Tracker 历史统一表达在 \(C_{n-1}\)；
2. 将 Unity 提供的当前 6 个 Tracker 世界变换转换到 \(C_n\)，并构造当前 Head trajectory；
3. 更新 configured、measured_valid、\(d^{off}\) 和 \(d^{on}\)；
4. 计算 \(\kappa\)、\(\rho\) 和本帧固定 hard 集合；
5. 从过去 60 帧生成 Tracker 历史摘要和 Past-only 区域运动先验，并在全部 DDIM step 间复用；
6. 将当前观测条件、当前 trajectory 和扩散状态送入 TargetDiT；
7. 通过 Projected DDIM 得到 final raw pose 与 deployed 144D pose；
8. 使用 Head 世界位置、floor 和目标骨架对 deployed pose 执行世界空间解析；
9. 输出结果，并把解析后的世界姿态、当前 Tracker 世界状态和当前 trajectory 写入滚动缓存。

冷启动阶段的缺失历史统一左补零，valid frame mask 保证 padding 不进入时序先验。

## 8. 训练目标与实现细节

### 8.1 单帧训练目标

RealtimePose 路径对完整 144D 姿态加噪：

\[
x_{n,k}
=
\sqrt{\bar\alpha_k}x_n
+\sqrt{1-\bar\alpha_k}\,\epsilon,
\qquad
\epsilon\sim\mathcal N(0,I).
\]

**式中：** \(x_n\) 是第 \(n\) 帧标准化后的干净 144D 姿态；\(x_{n,k}\) 是在随机扩散时间步 \(k\) 得到的带噪姿态；\(\bar\alpha_k\) 是累计信号保留系数；\(\epsilon\) 是与姿态同形的标准高斯噪声；\(I\) 是 144 维单位协方差矩阵。

默认采用 \(x_0\)-prediction 和逐维 MSE，因此扩散重建项为：

\[
\mathcal L_{diff}
=
\mathbb E_{n,k,\epsilon}
\left[
\frac{1}{144}\left\|
\hat x_{n,k}^{0,raw}-x_n
\right\|_2^2
\right].
\]

**式中：** \(\mathcal L_{diff}\) 是 raw 分支的扩散重建损失；\(\hat x_{n,k}^{0,raw}\) 是 TargetDiT 对干净姿态的直接预测；系数 \(1/144\) 表示对全部姿态维度取均值；\(\mathbb E_{n,k,\epsilon}\) 表示对训练帧、随机时间步和前向噪声取期望。实现允许通过训练参数把该重建项切换为 L1，但默认使用 MSE。

TargetDiT 输出 raw 预测后，再通过与部署相同的投影得到 deployed 预测。单帧总损失写为：

\[
\mathcal L_{single}
=
\lambda_{diff}\mathcal L_{diff}
+
\lambda_{aux}
\sum_{q\in\mathcal Q}\lambda_q\mathcal L_q,
\]

**式中：** \(\mathcal L_{single}\) 是单帧总损失；\(\lambda_{diff}\) 和 \(\lambda_{aux}\) 分别控制扩散重建项与整组辅助几何项；\(\mathcal Q\) 是辅助监督索引集合；\(q\) 表示其中一个监督项；\(\mathcal L_q\) 与 \(\lambda_q\) 分别是该项损失及其内部权重。

辅助监督集合为：

\[
\mathcal Q=
\{
global\ rot,\ local\ rot,\ tracker\ rot,\ FK,\ tracker\ pos,
root,\ world\ joint,\ head\mbox{-}root,\ future\ leg,\ contact
\}.
\]

**式中：** \(\mathcal Q\) 中的 global/local/tracker rot 分别表示全局关节旋转、局部关节旋转和有效 Tracker 对应关节旋转；FK 和 tracker pos 表示骨架关节位置及有效非 Head Tracker 位置；root、world joint 和 head-root 表示 Root yaw、世界关节及 Head-to-Root 水平关系；future leg 和 contact 表示两个辅助头。

各组监督的职责为：

| 损失组 | 主要作用对象 | 目的 |
|---|---|---|
| 扩散与姿态生成 | Raw pose | 学习扩散目标、全局旋转和局部旋转 |
| Tracker 几何一致性 | Raw rotation、deployed joint position | 防止网络依赖投影，并约束有效非 Head Tracker 位置 |
| 世界空间监督 | Deployed Root 与世界关节 | 学习 Root yaw、世界关节和 Head-to-Root 水平关系 |
| 辅助监督 | Future-leg 与 contact heads | 学习腿部短期趋势和双脚接触 |

当前默认单帧损失权重为：

| 层级 | 权重 | 默认值 |
|---|---|---:|
| 总损失 | \(\lambda_{diff}\) | 1.0 |
| 总损失 | \(\lambda_{aux}\) | 1.0 |
| 辅助项 | global rotation | 1.0 |
| 辅助项 | local rotation | 1.0 |
| 辅助项 | tracker rotation | 1.0 |
| 辅助项 | FK | 2.0 |
| 辅助项 | tracker position | 10.0 |
| 辅助项 | root | 1.0 |
| 辅助项 | world joint | 1.0 |
| 辅助项 | head-root | 1.0 |
| 辅助项 | future leg | 0.5 |
| 辅助项 | contact | 0.1 |

即使某个关节最终会被 hard projection 覆盖，raw 分支仍必须学习自行预测该关节旋转。Tracker 位置误差使用径向 Huber，默认阈值为 0.05 m。

### 8.2 闭环与时序监督

训练 rollout 和在线部署使用相同的历史更新规则：

\[
\mathcal H_{n+1}^{pose}
=\operatorname{ShiftAppend}
\left(
\operatorname{ReExpr}_{C_{n-1}\rightarrow C_n}(\mathcal H_n^{pose}),
\operatorname{sg}(\tilde x_n)
\right).
\]

**式中：** \(\mathcal H_n^{pose}\) 是预测第 \(n\) 帧前使用的 60 帧姿态历史；\(\operatorname{ReExpr}_{C_{n-1}\rightarrow C_n}\) 按第 2.1 节规则把整段旧历史旋转到新的历史参考系；\(\tilde x_n\) 是位于 \(C_n\) 的 deployed pose；\(\operatorname{sg}\) 表示 stop-gradient，当前默认不让后续 rollout 损失穿过历史回传到上一帧预测；\(\operatorname{ShiftAppend}\) 表示移除最早帧并在右侧追加新姿态。

短 rollout 在统一世界系中监督：

- 预测帧之间的关节速度；
- 相邻关节旋转的相对变化；
- 连续接触期间的双脚位移；
- 后续帧自身的单帧生成与几何损失。

下一步历史只能追加上一帧 deployed 预测，不读取后续真值姿态历史。

### 8.3 动态观测训练场景

训练覆盖五类等权场景，每类默认概率为 0.2：

1. 持续六点；
2. 持续三点；
3. 三点切换到六点；
4. 六点切换到三点；
5. 六点配置下两个非 Head Tracker 同步掉线并重连。

其中“三点”固定指 Head、Left Wrist 和 Right Wrist；“六点”指六个 Tracker 槽位全部配置。场景 5 的两个掉线 Tracker 从五个非 Head 槽位中按当前任务生成规则选取。

这些场景使 \(\kappa\)、\(\rho\) 和 hard gate 在训练与部署中面对一致的状态变化。当前训练范围不额外加入测量噪声、重连跳变或其他掉线组合；它们属于后续实验变量。

### 8.4 默认实现配置

| 配置 | 默认值 |
|---|---:|
